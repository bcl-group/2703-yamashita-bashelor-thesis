## 1. 記号の対応（ここが一番重要）

資料 p.260 式(5.4)(5.5) の定義:

```
h(t) = f( W x(t) + U h(t-1) + b )      … (5.4)
y(t) = g( V h(t) + c )                  … (5.5)
```

| 資料の記号 | 意味 | 引き継ぎ指示書の記号 | NumPy版の変数名（案） | shape |
|---|---|---|---|---|
| `W` | 入力→隠れ層の重み | `W_xh` | `W` | (input_dim, hidden_dim) |
| `U` | 前時刻の隠れ層→隠れ層の重み（再帰） | `W_hh` | `U` | (hidden_dim, hidden_dim) |
| `V` | 隠れ層→出力層の重み | `W_hy` | `V` | (hidden_dim, output_dim) |
| `b` | 隠れ層のバイアス | `b_h` | `b` | (hidden_dim,) |
| `c` | 出力層のバイアス | `b_y` | `c` | (output_dim,) |
| `f` | 隠れ層の活性化関数 | tanh | `np.tanh` | - |
| `g` | 出力層の活性化関数 | なし（恒等） | 恒等写像 | - |
| `p(t)` | 隠れ層の活性化前の値 (5.6) | - | `p` | (batch, hidden_dim) |
| `q(t)` | 出力層の活性化前の値 (5.7) | - | `q` | (batch, output_dim) |

> 資料 p.261 式(5.15): sin波の予測では出力層は線形活性 `y(t) = V h(t) + c`、
> 誤差関数は式(5.16) の2乗誤差。→ **g は恒等関数**でよい（[資料参照]）。

- **注意**: 資料は `W x(t)`（列ベクトル前提）だが、NumPy実装では
  バッチを行方向に置く `x @ W` の形にするため、**行列の並びが転置**になる。
  この点はコードコメントで `[PyTorch処理をNumPyで再実装]` として明示する。

## 3. forward の式とコードの対応（資料 p.260）

| 資料の式 | 内容 | NumPy実装 |
|---|---|---|
| (5.6) | `p(t) = W x(t) + U h(t-1) + b` | `p = x_t @ W + h_prev @ U + b` |
| (5.4) | `h(t) = tanh(p(t))` | `h = np.tanh(p)` |
| (5.7) | `q(t) = V h(t) + c` | `q = h_last @ V + c` |
| (5.15) | `y(t) = q(t)`（線形活性） | `y = q` |
| (5.16) | `E = 1/2 Σ ||y - t||^2` | `mean_squared_error()` |

初期隠れ状態 `h(-1)` は 0 ベクトル（資料に明示は確認できていない → [補助処理] として扱い、
「最初の時刻には前時刻の情報が無いため0で初期化する」とコメントする）。

## 4. BPTT の式とコードの対応（資料 p.262-264）

誤差項の定義（p.260 式(5.8)(5.9)）:
```
e_h(t) := ∂E/∂p(t)      e_o(t) := ∂E/∂q(t)
```

| 資料の式 | 内容 | NumPy実装（予定） |
|---|---|---|
| (5.18) | `e_o(t) = g'(q(t)) ⊙ (y(t) - t(t))` | `e_o = (y - t)`（gは恒等なので g'=1） |
| (5.17) | `e_h(t) = f'(p(t)) ⊙ V^T e_o(t)` | `e_h = (1 - h**2) * (e_o @ V.T)` |
| (5.22)(5.23) | `e_h(t-1) = e_h(t) ⊙ (U f'(p(t-1)))` | 時間を遡るループ内で `e_h = (e_h @ U.T) * (1 - h_prev**2)` |
| (5.10) | `∂E/∂W = Σ e_h(t-z) x(t-z)^T` | `dW += x_t.T @ e_h` |
| (5.12) | `∂E/∂U = Σ e_h(t-z) h(t-z-1)^T` | `dU += h_prev.T @ e_h` |
| (5.11) | `∂E/∂V = e_o(t) h(t)^T` | `dV = h_last.T @ e_o` |
| (5.13) | `∂E/∂b = Σ e_h(t-z)` | `db += e_h.sum(axis=0)` |
| (5.14) | `∂E/∂c = e_o(t)` | `dc = e_o.sum(axis=0)` |
| (5.24)〜(5.28) | パラメータ更新 `θ ← θ - η * 勾配` | SGDの更新式そのまま |

- 資料 p.264 より、遡る時刻数 τ は「10〜100程度」。
  今回は `maxlen = 25` なので、**系列全体（25ステップ）を遡る**予定。

- 転置の向きは、資料が列ベクトル・NumPy版が行ベクトル（バッチ先頭）なので
  `x(t)^T` が `x_t.T @ e_h` に対応する。この読み替えはコードコメントで明示する。
