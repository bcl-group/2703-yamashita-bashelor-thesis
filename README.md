# RNN Neuro Surrogate
### RNNを用いた神経細胞モデル（Hodgkin–Huxleyモデル）の代理モデル構築による高速シミュレーション
# 要約

### 脳
- 脳は生物の思考や行動などの情報処理を司る
    - ニューロンのネットワークを介したスパイク伝播によってなされる[1]．
        - スパイク：ニューロンの膜電位がスパイク状に急上昇すること
            - 隣接するニューロンがスパイクを起こす
            - 影響を受けて膜電位が上昇
            - $Na$チャネルが開き，外部の$Na^+$が一気に流入
            - 膜電位が急上昇（スパイク）
            - 遅れて$K$チャネルが開き，内部の$K^+$が流出
            - 元の電位よりも下がる
            - 1度スパイクするとしばらくスパイクしない期間（不応期）があるため逆伝播は起こらない
            - HHモデルを用いた詳しいニューロン発火の流れはHHモデルの章で
- 脳の情報処理の全過程を観測したい
    - 脳内の膨大な数（約$10^{11}$個）のニューロンを同時に観測する必要があり，実現は困難である[2]．
        - 一方で、個々のニューロンの挙動はHodgkin-Huxleyモデルなど数理モデルによって表現可能である[1]．
        - ニューロンの個々の振る舞いを記述する数理モデルを組み合わせた脳モデルを
作り、脳シミュレーションを行うことができる．


### Multi-Compartmentモデル
- Multi-Compartmentモデルは、ニューロンの空間形状を考慮した数理モデルであり、刺激シーケンスの弁別や排他的論理和演算などの複雑なニューロンの特性を再現できる[3][4]。
- ニューロンを複数のコンパートメントで表現し、各コンパートメントは膜電位と複数の隠れ変数を保持するため、多くのメモリを必要とする[1]。
- マウス脳規模（約10^8～10^9個のニューロン）のシミュレーションでも、富岳でも扱いきれないほど空間計算量が増大する[5]。
- 隠れ変数はイオン輸送を制御する重要な変数であるが、脳シミュレーションでは直接利用しないため、メモリ消費の要因となっている[1]。
- 大規模脳シミュレーションの実現には、ニューロンモデルの空間計算量削減が重要である。

## 研究目的
- 空間計算量を削減するため、少ない隠れ変数で同等の膜電位応答を再現できる代理モデル（surrogate model）の構築を目指す。
- Multi-Compartmentモデルは複雑であるため、まずはより基本的なHodgkin-Huxleyモデルを対象として代理モデルの有効性を検証する[6]。
- Hodgkin-Huxleyモデルは空間形状を考慮しない一方で、Multi-Compartmentモデルと同様にイオン輸送を制御する隠れ変数を持つ[6]。
- 本研究では、Hodgkin-Huxleyモデルに対する代理モデルを構築することを目的とする。
