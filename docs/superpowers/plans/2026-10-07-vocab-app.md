# 英語論文単語帳アプリ 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 英単語を入力すると品詞別の日本語訳を表示し、Enter 1回で保存できる単語帳（一覧・クイズ付き）をローカルWebアプリとして作る。

**Architecture:** 原形変換・辞書検索・単語帳保存をそれぞれ独立した Python モジュールにし、Flask の `app.py` は HTTP との橋渡しだけを担う。画面は `static/` の1ページ HTML + 素の JS で、JSON API を叩く。

**Tech Stack:** Python 3.10+、uv、Flask、pytest、SQLite（標準ライブラリ `sqlite3`）、素の HTML/CSS/JS

**Spec:** `docs/superpowers/specs/2026-10-07-vocab-app-design.md`

## Global Constraints

- アプリのルートは `単語帳アプリ/`。起動は `uv run python 単語帳アプリ/app.py`、URL は `http://127.0.0.1:5000`
- テストは `uv run pytest 単語帳アプリ/tests -q`（リポジトリ直下で実行）
- 依存はリポジトリの `pyproject.toml` に追加する: `flask`（通常）、`pytest`（dev）
- 辞書は `単語帳アプリ/data/`（`.gitignore` で除外）: `wnjpn.db`、`ejdict.tsv`
- 単語帳は `単語帳アプリ/vocab.json`（UTF-8、`ensure_ascii=False`、`indent=2`、git 管理）
- 品詞名の一覧（この順で表示）: `名詞, 動詞, 形容詞, 副詞, 前置詞, 接続詞, 代名詞, 助動詞, その他`
- WordNet 品詞記号の対応: `n→名詞, v→動詞, a→形容詞, s→形容詞, r→副詞`
- 保存内容の初期値は、品詞ごとに WordNet の訳を上位 **3** 件
- クイズの重み: `w = (1 + wrong) * (1 / (1 + correct)) * (1 + d / 7)`。d は `last` からの経過日数（未出題なら 7）
- サーバは `127.0.0.1` だけで待ち受ける（外部公開しない）

## WordNet DB の実スキーマ（確認済み）

- `word(wordid, lang, lemma, pron, pos)`: `lang` は `'eng'` / `'jpn'`。英語 lemma はすべて小文字、複合語は `_` 区切り（`neural_network`）
- `sense(synset, wordid, lang, rank, lexid, freq, src)`: 英語側の `freq` に頻度（NULL あり）
- `synset(synset, pos, name, src)`: `pos` は `n, v, a, r` の4種類

## Review Focus

1. PDF からコピーした語には `Networks,` や `“model”` のように大文字・記号が付く → 前後の英字以外を除いて小文字化してから検索する（Task 1 でテスト）
2. 複合語・ハイフン語（`neural network`、`state-of-the-art`）→ WordNet では空白を `_` に、EJDict は空白のまま引き、`-` は残す（Task 2 でテスト）
3. 同じ訳の重複や空文字が保存内容に入る → 保存時に前後空白を除き、空を捨て、順序を保って重複を除く（Task 3 でテスト）
4. 実在する語を語尾規則で壊す（`analysis`→`analysi`、`bus`→`bu`）→ 入力そのものが辞書にあれば変換しない（Task 1 でテスト）
5. 単語帳に1語しかないときのクイズ → 「直前と同じ語を出さない」規則で出題不能にならず、その1語を出す（Task 3 でテスト）

WordNet の検索 SQL（品詞ごとに Python 側で順序を保って重複除去する）:

```sql
SELECT sy.pos, jw.lemma
FROM word w
JOIN sense s   ON s.wordid = w.wordid AND s.lang = 'eng'
JOIN synset sy ON sy.synset = s.synset
JOIN sense js  ON js.synset = s.synset AND js.lang = 'jpn'
JOIN word jw   ON jw.wordid = js.wordid
WHERE w.lang = 'eng' AND w.lemma = ?
ORDER BY COALESCE(s.freq, 0) DESC, s.synset, js.rowid
```

接続は `sqlite3.connect(f"file:{path}?mode=ro", uri=True, check_same_thread=False)`。起動を速くするため、`has()` 用に英語 lemma の集合を初回利用時に1回だけ読み込む。
EJDict はファイル全体を `dict[str, str]` に読み込む。見出し語は `,` で分割し、それぞれを小文字キーにする。同じキーが複数行あれば訳を ` / ` でつなぐ。
`Dictionary.lookup` の `exists` は「WordNet か EJDict のどちらかにある」。

### Task 3: 単語帳の保存とクイズ出題

**Files:**
- Create: `単語帳アプリ/vocab/store.py`
- Test: `単語帳アプリ/tests/test_store.py`

**Interfaces:**
- Consumes: `POS_ORDER`（Task 2）
- Produces:
  - `class CorruptVocabError(Exception)`
  - `quiz_weight(entry: dict, now: datetime) -> float`
  - `class VocabStore(path: Path)`（生成時に読み込み。ファイルがなければ空。JSON が壊れていれば `CorruptVocabError`）
    - `list(q: str = "", pos: str = "", sort: str = "new") -> list[dict]`（`sort` は `"new"` か `"alpha"`。`q` は単語と訳の部分一致、大文字小文字を区別しない）
    - `get(word: str) -> dict | None`
    - `put(word: str, senses: list[dict], example: str = "", now: datetime | None = None) -> dict`（新規なら `created_at` と `review` を作り、既存なら `created_at` と `review` を引き継ぐ。不正なら `ValueError`）
    - `delete(word: str) -> bool`
    - `record(word: str, result: str, now: datetime | None = None) -> dict`（`result` は `"correct"` / `"wrong"`、それ以外・未登録語は `ValueError` / `KeyError`）
    - `next_quiz(exclude: str | None = None, rng: random.Random | None = None, now: datetime | None = None) -> dict | None`
  - 日時は `datetime.now().isoformat(timespec="seconds")` 形式の文字列で保存する

### Task 6: 画面

**Files:**
- Create: `単語帳アプリ/static/index.html`, `単語帳アプリ/static/app.js`, `単語帳アプリ/static/style.css`, `単語帳アプリ/README.md`

**Interfaces:**
- Consumes: Task 4 の API

画面仕様は設計書 5章のとおり。決めておく点:
- 起動時に `/api/status` を呼び、`dictionary: false` なら上部に「辞書がありません: `uv run python 単語帳アプリ/setup_dict.py` を実行してください」を出す。品詞の選択肢は `pos_list` を使う
- 登録タブ: 単語入力欄で Enter → `/api/lookup`。`saved` があればそれを、なければ `default` を編集欄に入れる。`lemma != normalize(input)` のとき「network として検索」と表示
- 編集欄にフォーカスがない状態、または単語入力欄で検索結果表示中に Enter → 保存（`PUT`）→ 「保存しました」を2秒表示 → 入力欄を空にしてフォーカス。例文欄（textarea）内の Enter は改行
- 訳チップ: ×で削除、各品詞行末の入力欄で Enter で追加。「品詞を追加」ボタン
- WordNet の他の訳はクリックで該当品詞に追加。EJDict の訳はクリックで品詞選択の小メニューを出し、選んだ品詞に追加
- 一覧タブ: 検索欄（入力のたびに再取得、300ms のデバウンス）、品詞の絞り込み、並び替え。行クリックで登録タブの編集画面へ。削除は `confirm()`
- クイズタブ: 単語表示 → クリック/Space で答え表示 → 「覚えた」(→キー) /「まだ」(←キー)。次の出題では `exclude` に直前の語を渡す。正答数・誤答数を小さく表示
- HTML 挿入は `textContent` で行い、`innerHTML` に辞書や入力の文字列を入れない
- README には セットアップ・起動・テストのコマンドと、辞書のライセンス（日本語WordNet: Princeton WordNet と同様の BSD 系、EJDict: CC0）を書く
