# 英語論文単語帳アプリ 設計書

- 作成日: 2026-10-07
- 対象: 英語論文を読む中で出会った単語を、品詞・意味（複数可）・例文付きで記録し、復習するローカルWebアプリ

## 1. 目的と成功条件

### 目的
英語論文で出会った単語をその場で調べ、品詞と意味を確認して手間なく保存する。保存した単語は一覧で管理し、クイズで復習する。

### 成功条件
- 英単語を入力すると、品詞ごとの日本語訳が自動で表示される
- 表示された内容に手を加えなければ、Enter 1回で保存できる
- 品詞・意味は1語につき複数持てる
- 辞書にない語（専門用語など）も手入力で保存できる
- ネット接続なしで動く（辞書の初回ダウンロード時を除く）

## 2. 全体構成

| 要素 | 内容 |
|---|---|
| サーバ | Python + Flask。リポジトリの uv 環境で実行する |
| 画面 | HTML + 素の JavaScript による1ページ。タブで「登録 / 一覧 / クイズ」を切り替える |
| 辞書1 | 日本語WordNet 1.1 `wnjpn.db`（SQLite、英語WordNetを含む）。品詞付きの訳を得る |
| 辞書2 | EJDict（CC0）`src/a.txt`〜`z.txt`。品詞なしの訳を幅広く得る |
| 単語帳 | `vocab.json`（UTF-8、インデント付き）。git で差分を追える |

起動コマンド:

```bash
uv run python 単語帳アプリ/app.py
```

起動後、ブラウザで `http://127.0.0.1:5000` を開く。

### ディレクトリ構成

```
単語帳アプリ/
├── app.py              # Flask アプリ（ルーティングのみ）
├── setup_dict.py       # 辞書のダウンロードと前処理
```

各モジュールは単独でテストできるようにし、`app.py` は HTTP と各モジュールの橋渡しだけを行う。

## 3. 辞書

### 3.1 セットアップ（`setup_dict.py`）
1. `https://github.com/bond-lab/wnja/releases/download/v1.1/wnjpn.db.gz`（約60MB）を取得し、`data/wnjpn.db` に展開する
2. `https://raw.githubusercontent.com/kujirahand/EJDict/master/src/{a..z}.txt` を取得し、`data/ejdict.tsv` に連結する
3. 既にファイルがあれば取得を省略する

### 3.2 WordNet 検索
- `word` テーブルで `lang='eng'` かつ `lemma` が一致する語を探し、`sense` で synset を得る
- 同じ synset に属する `lang='jpn'` の語を日本語訳とする
- synset の品詞記号を日本語名に変換する

  | 記号 | 品詞 |
  |---|---|
  | `n` | 名詞 |
  | `v` | 動詞 |
  | `a`, `s` | 形容詞 |
  | `r` | 副詞 |

- 品詞ごとに、訳を英語側の sense の頻度（`freq`）が高い synset 順に並べ、重複を除く
- 英語 lemma は小文字で比較する。複合語は WordNet の表記（`neural_network`）に合わせ、空白を `_` に置き換えて検索する

### 3.3 EJDict 検索
- `data/ejdict.tsv` を起動時にメモリへ読み込み、見出し語（小文字）→ 訳文字列の辞書にする
- 訳文字列を ` / ` で分割し、それぞれを1つの候補として返す
- 品詞情報はないため、画面では「辞書の訳（品詞なし）」として表示する

### 3.4 原形への変換（`lemmatize.py`）
入力を小文字化・前後の空白除去したのち、次の順で候補を作り、どちらかの辞書に存在する最初の語を採用する。

1. 入力そのもの
2. 語尾規則で作った候補
   - `-ies` → `-y`（studies → study）
   - `-es` → 除去（processes → process）
   - `-s` → 除去（networks → network）
   - `-ied` → `-y`、`-ed` → 除去、`-ed` → `-e`（used → use）
   - `-ing` → 除去、`-ing` → `-e`（computing → compute）
   - 子音重複の除去（stopped → stop）
3. 同梱の不規則変化表（`vocab/irregular.py` に約100語: ran → run, data → datum, analyses → analysis など）。規則2より先に調べる

どれも見つからなければ、入力そのものを見出し語として「見つかりません」を返す。変換した場合、画面に「network として検索」と表示する。

## 4. データ形式

`vocab.json` は単語オブジェクトの配列。

```json
{
  "word": "network",
  "senses": [
    {"pos": "名詞", "meanings": ["ネットワーク", "網状組織"]},
    {"pos": "動詞", "meanings": ["人脈を作る"]}
  ],
  "example": "We trained a recurrent neural network ...",
  "created_at": "2026-10-07T21:00:00",
  "updated_at": "2026-10-07T21:00:00",
  "review": {"correct": 0, "wrong": 0, "last": null}
}
```

- `word` は原形・小文字で、重複を許さない（キー）
- `pos` は「名詞 / 動詞 / 形容詞 / 副詞 / 前置詞 / 接続詞 / 代名詞 / 助動詞 / その他」から選ぶ
- `example` は空文字可
- 書き込みは一時ファイルに書いてから置き換え、途中で落ちても壊れないようにする

## 5. 画面と操作

### 5.1 登録タブ
1. 英単語を入力して Enter
2. 原形に変換して辞書を検索し、次を表示する
   - **保存内容（編集可）**: 品詞ごとに WordNet の訳を上位3件まで入れた状態。訳はチップ表示で、×で削除、入力欄で追加、品詞の追加・削除ができる
   - **WordNet の他の訳**: 上位3件以外の訳。クリックで保存内容に追加
   - **辞書の訳（品詞なし）**: EJDict の訳。クリックすると品詞を選んで保存内容に追加
   - **例文**: 論文中の一文を貼り付ける欄
3. Enter（または保存ボタン）で保存し、入力欄を空にして次の単語へ戻る
4. 登録済みの単語なら、保存済みの内容を保存内容欄に出して編集モードにする（辞書の候補も並べて表示）
5. 辞書にない語は保存内容を空で表示し、品詞と意味を手入力して保存する。意味が1つもない場合は保存できない

### 5.2 一覧タブ
- 単語・訳の部分一致で検索、品詞で絞り込み
- 並び順: 登録日の新しい順（初期値）/ アルファベット順
- 各行から編集（登録タブと同じ編集画面）と削除（確認ダイアログあり）

### 5.3 クイズタブ
- 英単語を1つ表示 → クリックまたは Space で品詞・意味・例文を表示 → 「覚えた」「まだ」を押す
- 「覚えた」で `correct`、「まだ」で `wrong` を1増やし、`last` を更新する
- 出題は重み付き乱択。重み w は次の式とする

  $$w = (1 + \text{wrong}) \times \frac{1}{1 + \text{correct}} \times \left(1 + \frac{d}{7}\right)$$

  d は最後に出題してからの日数（未出題なら 7）。間違いが多い語、しばらく見ていない語ほど出やすい
- 直前に出した語は続けて出さない

## 6. API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/lookup?word=...` | 原形・WordNet の品詞別訳・EJDict の訳・登録済みデータ（あれば）を返す |
| GET | `/api/words?q=&pos=&sort=` | 一覧の取得 |
| PUT | `/api/words/<word>` | 新規保存または更新 |
| DELETE | `/api/words/<word>` | 削除 |
| GET | `/api/quiz/next` | 次の出題 |
| POST | `/api/quiz/<word>` | `{"result": "correct" | "wrong"}` を記録 |

## 7. エラー処理
- 辞書ファイルがない: 起動時に検出し、画面上部に `uv run python 単語帳アプリ/setup_dict.py` を実行するよう表示する。辞書なしでも手入力での登録・一覧・クイズは使える
- 辞書にない語: 5.1 の5のとおり
- 空入力・英字以外のみの入力: 検索せずにメッセージを出す
- `vocab.json` が壊れている: 起動時にエラーを表示し、上書きしない
- 単語帳が空の状態でクイズを開く: 「単語がまだありません」と表示する

## 8. テスト（pytest）
- `lemmatize`: 各語尾規則、不規則変化、該当なし
- `dictionary`: テスト用の小さな SQLite と TSV を作り、品詞変換・並び順・重複除去・分割を確認
- `store`: 保存・更新・削除・重複キー・壊れた JSON の検出・クイズの重み計算
- `app`: Flask のテストクライアントで各 API の正常系と主なエラー

## 9. 範囲外
- 発音記号・音声
- 複数端末での同期
- 論文名の記録（必要になったら `source` フィールドとして追加する）
