## 目指す姿
- 神経細胞モデルの微分方程式をすべて RNN に置き換える
  - HH（1コンパートメント）
    - V, m, h, n の式を RNN 1つで置き換える（I → V）
  - Multi-Compartment
    - 各コンパートメントの HH 式を RNN にする
    - コンパートメント間の結合（ケーブル方程式）も RNN にする
  - ODE を数値的に解いた場合と、精度・計算量を比べる
