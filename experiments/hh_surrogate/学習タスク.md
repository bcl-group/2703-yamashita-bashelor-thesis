# HHモデルのRNN代理モデル：実験設定と評価方法

## 1. 目的
Hodgkin-Huxley（HH）モデルを dt = 0.01 ms の陽的オイラー法で解いたものの代理モデル（サロゲート）を、
NumPy のみで実装した RNN で作る。入力電流 I(t) を1時刻ずつ入れ、膜電位 V(t+dt) を1時刻ずつ出す
（オイラー法と同じ1:1の入出力）。構造の異なる2つのモデルを比較する。

## 2. 教師データ
どれも `src/neuron/hh.py` と同じ式を、dt = 0.01 ms の陽的オイラー法で解いたもの。保存している変数は t, I_ext, V, m, h, n。

| | teacher_thesis | teacher_ou（モデル2の改訂版で使う） |
|---|---|---|
| 生成 | `experiments/hh/make_dataset.py` | `experiments/hh/make_dataset_multi.py ou` |
| 元の条件 | 棟近先輩の卒業論文 Algorithm 2 | Learning flow functions §4.1（軌道を多数・初期状態ランダム）と、Traub の教師データ（基準レベル＋揺らぎ）の組み合わせ |
| 軌道 | 1本 × 900 ms（90,000 ステップ） | 100本 × 1000 ms（各 100,000 ステップ） |
| 初期状態 | V(0) = −65 mV、m, h, n はその電位での定常値 | V(0) ~ U[−90, 50] mV、m, h, n ~ U[0, 1] |
| 入力電流 | 10 ms ごとに 0〜20 µA/cm² の一様乱数で値を変える階段状の電流（seed = 0） | 基準レベル（U[0, 20] を 100〜1000 ms 保つ）＋ OU 過程の揺らぎ（標準偏差 σ ~ U[0, 4]、相関時間 1 ms）。[−5, 30] µA/cm² に収める（`level_ou_current`） |
| スパイク数 | 53 | 1本あたり平均 61（4〜84） |
| 分割 | 900 ms 全体で学習する | 100本すべてで学習する |

汎化は、どちらも学習に使っていない別の電流（§5）で評価する。teacher_ou は数百 MB あるので git では追跡しない（作り直せる）。

### teacher_ou にした理由
- 代理モデルが学ぶのは、オイラー法1ステップの写像 (V, m, h, n)(t), I(t) → (V, m, h, n)(t+dt) である。
  電流の波形を覚える必要はなく、閉ループで通る (状態, 電流) の組を学習データがカバーしていればよい。
- teacher_thesis では、同じ電流が長く続く場面（閾値付近で静止に落ち着く場面など）がない。
  基準レベルを 100〜1000 ms 保つことで、定常電流に近い区間を入れる。
- OU 過程の揺らぎで、パルスの立ち上がり・立ち下がりのような速い変化を入れる。
  dt ごとに I を入れる形なので、揺らぎを細かくしても計算量は増えない。
- 初期状態をランダムにして、閉ループで予測がずれたときに入る「1本の軌道の上にない状態」も入れる。

## 3. モデル
入力と出力は、2つのモデルで同じにする。
- 入力：I(t)（1時刻ずつ）
- 出力：V(t+dt)（1時刻ずつ）

### 3.1 モデル1：RNN 1個（`experiments/hh_surrogate/hh_surrogate.py`）
    h(t)    = tanh( I(t) W_xh + h(t−1) W_hh + b_h )
    V(t+dt) = h(t) W_hy + b_y
- 隠れ状態 h を時刻をまたいで持ち越す（Elman 型 RNN、many-to-many）
- 推論では h = 0 から始め、電流全体を1本の系列として流す

### 3.2 モデル2：RNN 3個（`experiments/hh_surrogate/hh_modular.py`）
HH の式の構造に合わせて、3つの RNN に分ける。各 RNN は入力を1時刻ずつ受け取り、自分の隠れ状態を持ち越す。

| ブロック | 置き換える部分 | 入力（次元） | 出力（次元） |
|---|---|---|---|
| RNN₁ | 速度定数 α(V), β(V) | V(t)（1） | α_m, β_m, α_h, β_h, α_n, β_n(t)（6） |
| RNN₂ | ゲート変数の式＋オイラー法1ステップ | α, β(t), m, h, n(t)（9） | 変化量 Δm, Δh, Δn（3） |
| RNN₃ | 膜電位の式＋オイラー法1ステップ | m, h, n(t), V(t), I(t)（5） | 変化量 ΔV（1） |

RNN₂, RNN₃ は1ステップの変化量 Δx = x(t+dt) − x(t) を出し、外で x(t) に足す（`--target delta`）。
次の時刻の値をそのまま出す形（`--target abs`）は改訂前の版で、比較のために残している。

推論（閉ループ）：

    初期状態: V = −65 mV、(m, h, n) = 定常値、各ブロックの隠れ状態 = 0
    各時刻 t:
        (α, β)          = max( RNN₁(V(t)), 0 )                         ← 速度定数は正
        (m, h, n)(t+dt) = clip( (m, h, n)(t) + RNN₂(α, β, m, h, n(t)), 0, 1 )   ← ゲート変数は 0〜1
        V(t+dt)         = V(t) + RNN₃(m, h, n(t), V(t), I(t))
        V と m, h, n を次の時刻の入力に戻す

- 外から与えるのは I(t) と初期状態だけ
- RNN₃ には更新前の m, h, n(t) を渡す（`hh.py` のオイラー法と同じ順番）
- 値域の制約（max と clip）は `eval --clip` で入れる

### 3.3 モデル2を改訂した理由（2026-11-13）
改訂前は、教師強制では HH とほぼ一致したが、閉ループでは V が −110 mV 付近に張り付いた。

| 確かめたこと | 結果 |
|---|---|
| 教師強制の1ステップ誤差と、正解の1ステップ変化量の標準偏差の比 | V 46 %、m 49 %、h 97 %、n 73 %。値そのものの誤差は小さく見えても、毎ステップ変化量と同じくらいの誤差が乗っていた |
| 片方だけ閉ループにする（他は正解を入れる） | V だけ・ゲート変数だけならそこそこ動くが、両方を回すと 1.5 ms で崩れる |
| 閉ループでの m の最小値 | −0.71（物理的にありえない値の偽の安定点に落ちていた） |

変化量を出す形にすると、教師強制の誤差は V で約 1/24、m で約 1/43、h で約 1/100 になった。
閉ループでも steady 10、sin 10Hz、pulse 20Hz でスパイク数が HH と一致した（teacher_thesis で学習）。
値域の制約は、変化量の形と組み合わせたときにはほとんど効かなかった。
残った問題は steady 5（HH は1発で静止するが、モデルは発火し続ける）と、ramp で発火の始まりが早いことである。
どちらも静止と連続発火の境目の近くで、teacher_thesis にその状態がほとんど含まれないことが原因と考え、teacher_ou を作った。

## 4. 学習方法とハイパーパラメータ

### 4.1 共通
| 項目 | 値 |
|---|---|
| 実装 | NumPy のみ（`src/rnn/`：SimpleRNN、BPTT、Adam を自作） |
| 隠れ層の次元 | 50 |
| 活性化関数 | 隠れ層 tanh、出力層 恒等関数 |
| 重みの初期化 | W_xh：Xavier（正規分布、σ = √(2/(n_in+n_out))）、W_hh：直交行列、W_hy：正規分布 σ = √(1/n_hidden)、バイアス 0 |
| 損失関数 | 平均二乗誤差（MSE、標準化した値で計算） |
| 最適化 | Adam（lr = 0.001、β₁ = 0.9、β₂ = 0.999、AMSGrad、PyTorch と同じ方式） |
| 系列の区切り方 | 10 ms（1,000 ステップ）ずつ、重ならないように区切る（端数は捨てる）。複数軌道のデータでは軌道ごとに区切る |
| 各区間の初期状態 | h = 0 |
| BPTT | 区間の中だけさかのぼる（1,000 ステップ） |
| Early Stopping | 使わない |
| 乱数の seed | 123 |
| BPTT の検算 | 数値微分との相対誤差（全パラメータで 1e−9 程度以下を確認済み） |

| データ | 区間の数 | ミニバッチ | エポック数 | 更新回数 |
|---|---|---|---|---|
| teacher_thesis | 89 | 10 区間 | 1000 | 9,000 |
| teacher_ou | 9,900 | 100 区間 | 150 | 14,850 |

教科書（『詳解ディープラーニング』5.1.5）の sin 波の学習と同じく、「系列を固定長に切る → 各区間を h = 0 から → シャッフルしてミニバッチ」の流れにしている。違いは次の3点。
- 全時刻で出力する（教科書は窓の最後の1点だけ）
- 区間どうしは重ならない（教科書は1点ずつずらす）
- モデル2では、入力に各時刻の正解の状態を使う（教師強制）

teacher_thesis では電流の切り替え（10 ms ごと）と区間の境目が一致するので、区間の中で I が変わる場面がない。
teacher_ou では I が毎ステップ変わるので、この偏りはない。

### 4.2 標準化
| モデル | 方法 |
|---|---|
| モデル1 | I と V をそれぞれ、学習データ全体の平均・標準偏差で標準化（I：平均 10.507、標準偏差 5.793 / V：平均 −56.890、標準偏差 22.943） |
| モデル2 | 各ブロックの入力・出力を、変数（列）ごとに学習データの平均・標準偏差で標準化。変化量を出すブロックは、変化量 Δx の平均・標準偏差で標準化する |

評価では、すべて物理単位（mV など）に戻してから誤差を計算する。

### 4.3 モデル2のブロックごとの学習（教師強制）
各ブロックを、正解データだけを使って別々に学習する。
- α, β の正解：npz の V から `hh.py` の式で計算
- m, h, n, V の正解：npz の値を1ステップずらしたものから、変化量 Δx = x(t+dt) − x(t) を作る

学習のときはブロックどうしをつながない。つなぐのは推論（評価）のときだけ。

## 5. 評価方法

### 5.1 評価に使う電流
学習電流に加えて、学習に使っていない7種類の電流で評価する。最初の6種類は棟近先輩の評価条件に合わせている。
- 長さ：300 ms
- 前後 10 ms は無入力
- dt：0.01 ms

| 名前 | 電流 | 出典 |
|---|---|---|
| steady 5 / 10 / 15 | 定常電流 5, 10, 15 µA/cm² | 卒論 p.17 §4.4.1 |
| ramp 0-30 | 0 → 30 µA/cm² に直線的に増加 | SINDyNeuroSurrogate の既定値 |
| sin 10Hz | 振幅 7.5、オフセット 7.5、10 Hz | 同上 |
| pulse 20Hz | 振幅 20、幅 25 ms、周期 50 ms | 同上 |
| OU 10±3 | 平均 10、標準偏差 3、相関時間 1 ms の OU 過程（seed = 0） | Jolivet et al. (2008) のモデル予測コンテストと同じ形 |

正解の V は、同じ電流で HH を計算して求める（V(0) = −65 mV から）。

### 5.2 指標（棟近先輩の SINDyNeuroSurrogate と同じ。`src/evaluation/`）
| 種類 | 指標 |
|---|---|
| 波形の誤差 | RMSE、MAE [mV] |
| スパイク列 | スパイク数、最初のスパイクまでの時間（latency）、スパイク間隔（ISI）の平均・標準偏差、平均 ISI の差（periodicity_gap） |
| スパイクの形 | 平均スパイク波形の相関（spike_shape_corr） |
| 1発ごとの特徴量（eFEL） | peak_voltage、AP_amplitude、AP_begin_voltage、AP_rise_rate、AP_fall_rate、AP_duration_half_width、AP_rise_time、AP_fall_time、AHP_depth、AHP_time_from_peak |
| 発散の判定 | 膜電位に NaN・inf がある、または |V| > 1000 mV |

モデル2では、閉ループの結果に加えて、**各ブロックに正解を入れたときの RMSE**（教師強制）も条件ごとに出す。閉ループで誤差が出たとき、どのブロックが原因かを切り分けるためである。
ただし教師強制の RMSE が小さくても閉ループで崩れることがある（§3.3）ので、モデルの良し悪しは閉ループの指標で判断する。
閉ループの RMSE は、スパイクの時刻が少しずれるだけで大きくなるので、スパイク数・ISI とあわせて見る。

### 5.3 計算コスト
1ステップあたりの演算回数を、先輩と同じ数え方で比べる。
- 数える演算：指数関数、除算、加減算、乗算
- 数える範囲：HH は右辺の評価のみで、オイラー法の更新は含めない。RNN は入出力の標準化を含める

| モデル | 合計演算回数 / ステップ |
|---|---|
| HH | 64 |
| モデル1（RNN 1個、隠れ層 50） | 5,454 |
| モデル2（RNN 3個、隠れ層 各 50） | 18,300 |

## 6. 実行方法（リポジトリのルートで）
    uv run python -X utf8 experiments/hh/make_dataset.py
    uv run python -X utf8 experiments/hh/make_dataset_multi.py ou
    uv run python -X utf8 experiments/hh_surrogate/hh_surrogate.py --epochs 1000

    # モデル2（改訂前：teacher_thesis、次の時刻の値を出す）
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py train --block 1
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py train --block 2
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py train --block 3
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py eval

    # モデル2（改訂版：teacher_ou、変化量を出す、値域の制約あり）。ブロックごとに --block 1, 2, 3
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py train --block 1 --target delta --epochs 150 --batch-size 100 --data data/hh/teacher_ou.npz --out results/hh_modular_ou
    uv run python -X utf8 experiments/hh_surrogate/hh_modular.py eval --dir results/hh_modular_ou --data data/hh/teacher_thesis.npz --clip

結果の保存先：`results/hh_surrogate/`（モデル1）、`results/hh_modular/`（モデル2 改訂前）、
`results/hh_modular_delta/`（変化量の形、teacher_thesis で学習）、`results/hh_modular_ou/`（改訂版）

## 7. 先行研究との違い
| | 棟近先輩（SINDy） | Learning flow functions（論文） | 本研究 |
|---|---|---|---|
| 学習する対象 | 微分方程式の右辺 dV/dt, dg′/dt | 任意時刻の V（フロー関数） | オイラー法1ステップの変化量 ΔV（モデル2では α, β, Δm, Δh, Δn も） |
| モデル | 基底関数の線形結合（STLSQ） | LSTM＋エンコーダ・デコーダ | Elman 型 RNN（初期は NumPy で自作、改良実験は PyTorch）、再帰のない MLP（Markov 型） |
| 1ステップ | dt = 0.05 ms | Δ = 10 ms | dt = 0.01 ms |
| 入力電流（学習） | 20 ms ごとの階段状 | 100 ms ごとの階段状 | 基準レベル＋OU の揺らぎ（改訂版） |
| 損失 | 最小二乗 | L1（棄却サンプリング、窓付き損失） | MSE |
