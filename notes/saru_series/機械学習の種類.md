# 教師あり学習
入力データと正解ラベル（教師データ）のセットを使って、両者の関係性を学習する
## 回帰
- 単回帰分析$$y = w_1 x + w_0 + \epsilon$$
    - 1つの変数から直線の関係性（一次式）で予測する
        - $x$: 説明変数
        - $y$: 目的変数
        - $w_1$: 傾き
        - $w_0$: 切片
        - $\epsilon$: 誤差項

- 重回帰分析$$y = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_p x_p + \epsilon = \mathbf{w}^T \mathbf{x} + \epsilon$$
    - 複数の変数から直線の関係性（一次式）で予測する
        - $\mathbf{x}$: 入力特徴量ベクトル $[1, x_1, x_2, \dots, x_p]^T$
        - $\mathbf{w}$: 重み（パラメータ）ベクトル $[w_0, w_1, w_2, \dots, w_p]^T$
        - $y$: 目的変数
        - $\epsilon$: 誤差項
- 多項式回帰$$y = w_0 + w_1 x + w_2 x^2 + \dots + w_d x^d + \epsilon = \sum_{j=0}^{d} w_j x^j + \epsilon$$
    - 直線ではなく、曲線を描く多項式を用いて複雑な変化傾向を捉える手法
        - $x$: 説明変数
        - $y$: 目的変数
        - $d$: 多項式の次数
        - $w_j$: 各項の重み
        - $\epsilon$: 誤差項

## 分類
- ロジスティック回帰$$P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$
    - 確率（0〜1）を算出し、データを2つのクラスに分類する手法。
        - $\mathbf{x}$: 入力特徴量ベクトル
        - $\mathbf{w}$: 重みベクトル
        - $b$: バイアス
        - $\sigma(z)$: シグモイド関数
- サポートベクターマシン（SVM）$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$$
    - 境界線（ハイパープレーン）とデータの距離（マージン）を最大化して境界を引く手法。
        - $\mathbf{w}^T \mathbf{x} + b = 0$: 決定境界（超平面）の式
        - $\mathbf{w}$: 法線ベクトル
        - $b$: バイアス
        - $y_i \in \{-1, 1\}$: クラスラベル
        - $\frac{2}{\|\mathbf{w}\|}$: マージン幅（最大化対象）

# 教師なし学習
正解ラベルのないデータを入力し、データ自身に潜む構造やパターン、特徴量を自律的に抽出する手法
## クラスタリング（データ群のグループ分け）
- k-means（k平均法）$$J = \sum_{k=1}^{K} \sum_{\mathbf{x} \in C_k} \|\mathbf{x} - \boldsymbol{\mu}_k\|^2$$
    - あらかじめ決めた数（k個）の中心点を基準に、近いもの同士を集める非階層型手法。
        - $K$: クラスタ数
        - $C_k$: $k$ 番目のクラスタに属するデータ集合
        - $\boldsymbol{\mu}_k$: クラスタ $C_k$ の重心（平均ベクトル）
        - $J$: クラスタ内誤差平方和（最小化対象）

## 次元削減・特徴抽出
- PCA（主成分分析）$$\mathbf{\Sigma} \mathbf{w}_1 = \lambda_1 \mathbf{w}_1$$
    - 情報量をできるだけ保ちながら、多次元データを2〜3次元に圧縮する線形手法。
        - $\mathbf{\Sigma}$: データの分散共分散行列
        - $\lambda_1$: 最大固有値（第1主成分の分散）
        - $\mathbf{w}_1$: 固有ベクトル（第1主成分の方向軸）

# 強化学習
試行錯誤を通じて、目的（報酬）を最大化する最適な振る舞いを学習
- Q学習（Q-Learning）$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$
    - 「ある状態でこの行動をとった時の価値（Q値）」を表に記録・更新していく基本手法。
        - $s$: 現在の状態
        - $a$: 現在選択した行動
        - $r$: 得られた即時報酬
        - $s'$: 遷移後の状態
        - $a'$: 遷移先で選択可能な次の行動
        - $\alpha$: 学習率 ($0 < \alpha \le 1$)
        - $\gamma$: 割引率 ($0 \le \gamma < 1$)
