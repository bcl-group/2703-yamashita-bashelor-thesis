## 1. 系列データと問題設定

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ sequence | 系列 | 順番に並んだデータ点の列。RNN の入力・出力（またはその一方）になる | p.5 §2.1 |
| ★ input sequence x⁽¹⁾…x⁽ᵀ⁾ | 入力系列 | 各時刻のデータ点 x⁽ᵗ⁾（実数ベクトル）の並び。時刻は上付きの括弧で表す | p.5 §2.1、p.6 第2段落 |
| target sequence y⁽ᵗ⁾ | 目標系列（教師系列） | 各時刻で出力してほしい正解の並び | p.5 §2.1 |
| ★ ŷ⁽ᵗ⁾ | 予測値 | モデルが時刻 t に出力した予測。ハット記号で正解 y と区別する | p.6 第2段落 |
| ★ time step | 時間ステップ | 系列の1つ分の位置。等間隔サンプリングの時刻でも、単なる順番でもよい | p.6 第2–3段落 |
| T | 系列長（最大時刻） | 有限の系列の最後の時刻番号 | p.5 §2.1–p.6 第1段落 |
| independence assumption | 独立性の仮定 | 学習データの各例が互いに無関係だという仮定。通常の NN が置いている前提で、時系列では成り立たない | p.2 第2段落 |
| context window / sliding window | 文脈窓 / スライディングウィンドウ | 各時点の前後の決まった数のデータをまとめて入力する方法。窓より遠い過去は扱えない | p.3 §1.1 第1段落 |
| ★ long-range dependency | 長期依存（性） | 離れた時刻どうしの関係。RNN の学習で最も難しい点の1つ | p.3 §1.1 第2段落 |
| Markov chain | マルコフ連鎖 | 次の状態が直前の状態だけで決まる確率モデル | p.3 §1.2 |
| hidden Markov model (HMM) | 隠れマルコフモデル | 観測できない離散状態の列から観測系列が生じるとするモデル。状態数が増えると計算量が急増する | p.3 §1.2 |
| connectionist model | コネクショニストモデル | 多数の単純なユニットのつながりで計算するモデル。ニューラルネットワークの別名として使われる | p.1 Abstract、p.4 第2段落 |
| Turing complete / universal Turing machine | チューリング完全 / 万能チューリング機械 | 任意の計算手順を表現できる性質。有限サイズの RNN でも理論上これを持つ | p.4 §1.3 |
| online setting | オンライン設定 | データが1つずつ届き、その都度処理する状況。未来のデータは使えない | p.22 第2段落 |

## 2. ニューラルネットワークの基礎

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| node / unit / artificial neuron | ノード / ユニット / 人工ニューロン | 入力の重み付き和を受け取り、活性化関数を通して値を出す計算の単位 | p.6 第4段落 |
| edge | 辺（結合） | ノード間の有向の接続。生物のシナプスに相当すると考える | p.6 第4段落 |
| weight w_jj′ | 重み | ノード j′ から j への結合の強さ。この論文では「to-from」の順で添字を書く（文献によって逆なので注意） | p.6 第5段落 |
| ★ activation function / link function l_j | 活性化関数 / リンク関数 | 重み付き和に掛ける非線形関数。隠れ状態の記号 h と区別するため l と書く | p.6 第4段落 |
| incoming activation a_j | 入力活性 | 活性化関数に入る前の重み付き和 | p.6 第6段落–p.7 第1段落 |
| ★ sigmoid σ | シグモイド関数 | 出力が 0〜1 の S 字型の関数。ゲートに使われる | p.7 第2段落 |
| ★ tanh φ | 双曲線正接関数 | 出力が −1〜1 の S 字型の関数。この論文では φ と書く | p.7 第2段落 |
| ReLU | 正規化線形関数（ランプ関数） | max(0, z)。深いネットワークの性能を上げることが多い | p.7 第2段落 |
| softmax | ソフトマックス関数 | 出力の合計が1になるように正規化する関数。多クラス分類の出力に使う | p.7 第3段落 |
| ★ linear output | 線形出力 | 回帰問題では、出力層に非線形関数をかけずにそのまま出すのが一般的 | p.7 第3段落 |
| multiclass / multilabel classification | 多クラス分類 / 多ラベル分類 | 1つのクラスを選ぶ分類 / 複数のラベルを同時に付けられる分類 | p.7 第3段落 |
| ★ regression | 回帰 | 連続値を予測する問題。膜電位の予測はこれに当たる | p.7 第3段落、p.8 第2段落 |
| feedforward network | 順伝播型ネットワーク | ノードの結合に循環がなく、入力層から出力層へ一方向に計算するネットワーク | p.8 §2.3 第1段落 |
| layer | 層 | 同じ段階で計算されるノードの集まり | p.8 §2.3 第1段落 |
| ★ loss function L(ŷ, y) | 損失関数 | 予測と正解のずれを数値化する関数。学習はこれを小さくするように進む | p.8 第2段落 |
| ★ backpropagation | 誤差逆伝播法 | 連鎖律を使って、損失の各重みについての微分を出力側から順に計算する方法 | p.8 第3段落 |
| chain rule | 連鎖律 | 合成関数の微分の規則。誤差逆伝播法の数学的な基礎 | p.8 第3段落 |
| ★ gradient descent | 勾配降下法 | 損失の勾配と逆向きに重みを少しずつ動かして最小化する方法 | p.8 第3段落 |
| δ_j | デルタ（誤差信号） | ノード j の入力活性についての損失の微分。逆伝播で層ごとに計算する | p.9 第3段落 |
| non-convex | 非凸 | 損失の形が複雑で、局所的な谷が複数ありうること。大域最小に達する保証がない | p.8 第3段落 |
| NP-hard / NP-complete | NP 困難 / NP 完全 | 効率的に厳密に解く方法が知られていない問題のクラス。NN の厳密な最適化はこれに当たる | p.8 第3段落、p.13 §3.2 |
| ★ stochastic gradient descent (SGD) | 確率的勾配降下法 | 学習データの一部（ミニバッチ）で勾配を計算して重みを更新する方法 | p.9 第2段落 |
| ★ mini-batch / batch size | ミニバッチ / バッチサイズ | 1回の更新に使うデータのまとまり / その個数 | p.9 第2段落 |
| ★ learning rate η | 学習率 | 1回の更新で重みを動かす大きさ | p.9 第2段落 |
| AdaGrad | AdaGrad（アダグラッド） | パラメータごとに過去の勾配の2乗和で学習率を調整する方法。学習率は単調に下がる | p.9 第2段落 |
| AdaDelta / RMSprop | AdaDelta / RMSprop | AdaGrad の改良。過去の勾配の2乗を減衰させながら平均し、学習率が下がりすぎないようにする | p.9 第2段落 |
| momentum | モメンタム（慣性項） | 過去の更新量を減衰させながら加えて、更新に勢いをつける方法 | p.9 第2段落 |
| Hessian-free optimization | ヘッセ行列フリー最適化 | 2階微分の情報を、ヘッセ行列を直接作らずに使う最適化法 | p.9 第2段落、p.16 第3段落 |
| ★ overfitting | 過学習 | 学習データには合うが、新しいデータでは性能が悪くなる状態 | p.4 §1.3 第3段落 |
| weight decay | 重み減衰 | 重みが大きくなりすぎないように罰則を加える正則化 | p.4 第4段落–p.5 第1段落 |
| dropout | ドロップアウト | 学習中にランダムにノードを無効にして過学習を防ぐ正則化 | p.5 第1段落 |
| regularization | 正則化 | 過学習を防ぐためにモデルに制約を加えること | p.4 第4段落 |
| end-to-end differentiable | 端から端まで微分可能 | 入力から損失まで全体が微分でき、勾配法でまとめて学習できること | p.4 第4段落 |
| architecture | アーキテクチャ | 層の数、各層のノード数、結合の仕方、活性化関数などのネットワークの設計 | p.10 第2段落 |
| genetic algorithm | 遺伝的アルゴリズム | 生物の進化を模した探索法。NN のアーキテクチャ探索に使われることがある | p.10 第2段落 |
| sparsity | スパース性 | 値の多くが0であること。ReLU は隠れ層にスパース性をもたらす | p.10 第3段落 |
| CNN (convolutional neural network) | 畳み込みニューラルネットワーク | 局所的なパターンを捉える順伝播型ネットワーク。画像認識で主流 | p.2 第1段落、p.9 第1段落 |

## 3. RNN の構造と学習

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ recurrent neural network (RNN) | 再帰型ニューラルネットワーク | 隣り合う時刻をつなぐ結合を持ち、前の時刻の状態を次に引き継ぐネットワーク | p.1 Abstract、p.10 §3 第4段落 |
| ★ recurrent edge | 再帰辺（再帰結合） | ある時刻のノードから次の時刻のノードへの結合。これが循環を作る | p.10 §3 第4段落 |
| self-connection | 自己結合 | ノードが次の時刻の自分自身につながる再帰辺 | p.10 §3 第4段落 |
| ★ hidden state h⁽ᵗ⁾ | 隠れ状態 | RNN が各時刻に持つ内部の値。過去の入力の情報を要約して保持する | p.4 第2段落、p.10 第4段落 |
| ★ W^hx, W^hh, W^yh | 入力→隠れ / 隠れ→隠れ / 隠れ→出力 の重み行列 | 単純 RNN の3種類の重み。W^hh が再帰の重み | p.10 第5段落の式、p.11 第1段落 |
| ★ bias b_h, b_y | バイアス | 各ノードが学習するオフセット（定数項） | p.11 第1段落 |
| ★ unfolding (in time) | （時間方向の）展開 | RNN を、時刻ごとに1層を持つ深い順伝播型ネットワークとして描き直すこと | p.11 第2段落、p.12 図4 |
| ★ weight sharing / weight tying | 重み共有 | 展開したネットワークのすべての時刻で同じ重みを使うこと | p.11 第2段落、p.13 第2段落 |
| ★ backpropagation through time (BPTT) | 時間方向の誤差逆伝播法 | 展開した RNN に誤差逆伝播法を適用する学習法（Werbos 1990） | p.11 第2段落 |
| ★ truncated BPTT (TBPTT) | 打ち切り BPTT | 誤差を逆伝播させる時刻数に上限を設ける方法。勾配爆発を抑えるが、長期依存は学習できなくなる | p.14 第2段落 |
| ★ vanishing gradient | 勾配消失 | 長い時間をさかのぼるほど勾配が指数的に小さくなり、遠い過去から学習できなくなる現象 | p.13 §3.2 第2段落 |
| ★ exploding gradient | 勾配爆発 | 逆に勾配が指数的に大きくなり、学習が不安定になる現象 | p.13 §3.2 第2段落 |
| continuously running network | 連続して動き続けるネットワーク | 系列の区切りなく入力を受け続けるネットワーク | p.14 第2段落 |
| local optimum | 局所最適解 | 周囲よりは損失が小さいが、全体の最小ではない点 | p.14 第3段落 |
| saddle point | 鞍点 | ある方向には極小、別の方向には極大になっている点。大きな NN では局所最適より多い | p.14 第3段落 |
| saddle-free Newton method | 鞍点回避型ニュートン法 | 鞍点に引き寄せられないよう改良したニュートン法 | p.16 第3段落 |
| Hopfield network | ホップフィールドネットワーク | 1982年に提案された再帰型ネットワーク。壊れたパターンから記憶したパターンを復元できる | p.11 §3.1 |
| Jordan network | ジョーダンネットワーク | 出力の値を特別なユニットに送り、次の時刻の隠れ層に戻すネットワーク | p.12 第1段落、p.13 図5 |
| ★ Elman network | エルマンネットワーク | 隠れ層の値を文脈ユニットに写し、次の時刻の隠れ層に戻すネットワーク。現在の単純 RNN と等価 | p.12 第2段落、p.14 図6 |
| context unit / state unit | 文脈ユニット / 状態ユニット | 前の時刻の値を保持して次の時刻に渡すユニット。Elman は文脈ユニット、Jordan は状態ユニットと呼ぶ | p.12 第2段落、脚注2 |
| XOR task | 排他的論理和課題 | Elman が時間方向に拡張して、RNN が時間依存を学習できることを示した課題 | p.12 第3段落–p.13 第1段落 |
| GPU | GPU（画像処理装置） | 並列計算が得意な演算装置。NN の学習を大幅に高速化する | p.16 第2段落 |
| Theano / Torch | Theano / Torch | GPU で NN を実装するためのソフトウェアライブラリ（2015年当時） | p.16 第2段落 |

## 4. LSTM

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ long short-term memory (LSTM) | 長短期記憶 | 隠れ層のノードを記憶セルに置き換え、勾配消失を克服した RNN（Hochreiter & Schmidhuber 1997） | p.16 §4 第4段落、p.17 §4.1 |
| 名前の由来 | — | 重み（ゆっくり変わる＝長期記憶）と活性値（すぐ変わる＝短期記憶）の中間の記憶を、記憶セルが担うことから | p.17 第2段落 |
| ★ memory cell | 記憶セル | ゲートと内部状態からなる LSTM の計算単位。添字 c で表す | p.17 第1段落、p.17 図9 |
| multiplicative node Π | 乗算ノード | 入力どうしの積を出すノード。ゲートの仕組みを作る | p.17 第2段落 |
| ★ input node g | 入力ノード | 現在の入力と前時刻の隠れ状態から、記憶セルに入れる候補の値を作るノード。通常 tanh | p.18 箇条書き「Input node」 |
| ★ gate | ゲート | 0〜1 の値（シグモイド）で他のノードの値に掛け算し、情報の流れを通す・止めるユニット | p.18 箇条書き「Input gate」 |
| ★ input gate i | 入力ゲート | 入力ノードの値をどれだけ記憶セルに入れるかを決める | p.18 箇条書き「Input gate」 |
| ★ internal state s | 内部状態（セル状態） | 記憶セルの中心にある線形のノード。重み1の自己結合で値を保持する | p.18 箇条書き「Internal state」 |
| ★ constant error carousel (CEC) | 定誤差カルーセル | 内部状態の重み1の自己結合のこと。誤差が消失も爆発もせずに時間をさかのぼって流れる | p.18 箇条書き「Internal state」 |
| ★ forget gate f | 忘却ゲート | 内部状態をどれだけ残すか（消すか）を決める。元の LSTM にはなく、2000年に追加された | p.18 箇条書き「Forget gate」、p.19 第2段落 |
| ★ output gate o | 出力ゲート | 内部状態（通常 tanh を通す）のうち、どれだけを出力するかを決める | p.18 箇条書き「Output gate」 |
| ⊙ pointwise multiplication | 要素ごとの積（アダマール積） | 同じ形のベクトルの要素どうしを掛ける演算 | p.18 箇条書き「Internal state」 |
| peephole connection | ピープホール結合 | 内部状態からゲートへの直接の結合。正確な時間間隔を測るタスクで有効とされる | p.19 第2段落 |
| stacked / multilayer LSTM | 多層 LSTM | 記憶セルの層を複数重ねた構造 | p.21 第2段落 |

## 6. 自然言語処理と評価指標

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| one-hot encoding | ワンホット表現 | 語彙の大きさの長さを持ち、該当する1か所だけが1のベクトル | p.25 §5.1 第2段落 |
| distributed representation / word embedding | 分散表現 / 単語埋め込み | 単語を意味を反映した低次元の実数ベクトルで表す方法 | p.25 第2段落 |
| word2vec / GloVe | word2vec / GloVe | 単語の共起統計から単語ベクトルを作るソフトウェア | p.25 第2段落 |
| recursive neural network | 再帰的（木構造）ニューラルネットワーク | 木構造に沿って計算するネットワーク。recurrent（時間方向の再帰）とは別物で、この論文の RNN は常に recurrent を指す | p.25 第3段落 |

## 8. 変数・記号一覧

- 論文はベクトル・行列の次元（shape）をほとんど明記していない。「shape」列は一般的な定義から補ったもの（**推測**）。次元は d_x（入力）、d_h（隠れ状態）、d_y（出力）と置く。
- HH サロゲートに当てはめると、x⁽ᵗ⁾ = I(t)（入力電流、d_x = 1）、ŷ⁽ᵗ⁾ = V̂(t)（予測膜電位、d_y = 1）。

### 8.1 系列の記号（📍 §2.1, p.5–6）

| 記号 | 意味 | shape |
|---|---|---|
| t | 時刻（時間ステップの番号）。上付きの括弧で書く | スカラー（整数） |
| T | 系列の最後の時刻（系列長） | スカラー |
| x⁽ᵗ⁾ | 時刻 t の入力 | (d_x,) |
| y⁽ᵗ⁾ | 時刻 t の正解（目標） | (d_y,) |
| ŷ⁽ᵗ⁾ | 時刻 t のモデルの予測 | (d_y,) |

時刻を下付きではなく上付きにするのは、ノードの番号（下付き添字）と区別するため（📍 p.6 第2段落）。

### 8.2 ノード単位の記号（📍 §2.2–2.3, p.6–10）

| 記号 | 意味 |
|---|---|
| j, j′ | ノードの番号。j′ が送り側、j が受け側 |
| w_jj′ | ノード j′ → j の重み。「to-from」の順で書く（文献によっては逆順） |
| a_j | ノード j の入力活性（重み付き和）：a_j = Σ_j′ w_jj′ v_j′ |
| l_j(·) | ノード j の活性化関数（link function）。隠れ状態 h と区別するため l で書く |
| v_j | ノード j の出力値：v_j = l_j(a_j) |
| σ(z) | シグモイド関数：1 / (1 + e⁻ᶻ) |
| φ(z) | tanh 関数：(eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ) |
| K, k | 分類のクラス数と、クラスの番号（softmax の出力ノード ŷ_k） |

### 8.3 学習の記号（📍 §2.3, p.8–10）

| 記号 | 意味 |
|---|---|
| L(ŷ, y) | 損失関数（予測と正解のずれ） |
| w | 重み（パラメータ全体） |
| η | 学習率 |
| (x_i, y_i) | i 番目の学習データ |
| F_i | i 番目のデータで計算した目的関数 |
| ∇_w F_i | F_i の w についての勾配 |
| δ_k | 出力ノード k の誤差信号：δ_k = (∂L/∂ŷ_k) · l′_k(a_k) |
| δ_j | 隠れノード j の誤差信号：δ_j = l′(a_j) Σ_k δ_k w_kj。∂L/∂a_j を表す |
| ∂L/∂w_jj′ | 重みの勾配：δ_j v_j′ |

SGD の更新式：w ← w − η ∇_w F_i

### 8.4 単純 RNN の記号（📍 §3, p.10–11）★

| 記号 | 意味 | shape |
|---|---|---|
| h⁽ᵗ⁾ | 時刻 t の隠れ状態 | (d_h,) |
| h⁽ᵗ⁻¹⁾ | 1つ前の時刻の隠れ状態 | (d_h,) |
| W^hx | 入力 → 隠れ層の重み | (d_h, d_x) |
| W^hh | 隠れ層 → 次時刻の隠れ層の重み（再帰の重み） | (d_h, d_h) |
| W^yh | 隠れ層 → 出力の重み | (d_y, d_h) |
| b_h, b_y | 隠れ層・出力層のバイアス | (d_h,), (d_y,) |

上付きの添字は「行き先・出どころ」の順（例：W^hx は x から h へ）。

$$
h^{(t)} = \sigma\left(W^{hx}x^{(t)} + W^{hh}h^{(t-1)} + b_h\right),\qquad
\hat y^{(t)} = \mathrm{softmax}\left(W^{yh}h^{(t)} + b_y\right)
$$

膜電位のような回帰では、softmax を外して線形出力にする（📍 p.7 第3段落）。

勾配消失の説明で使う記号（📍 §3.2, p.13–14）：

| 記号 | 意味 |
|---|---|
| τ | 入力を与える時刻（誤差を計算する時刻 t より前） |
| t − τ | 2つの時刻の差。大きいほど勾配が指数的に消失または爆発する |
| w_jj | 隠れノード j の自己結合の重み。\|w_jj\| < 1 なら消失、> 1 なら爆発しやすい |

### 8.5 LSTM の記号（📍 §4.1, p.17–20）★

| 記号 | 意味 | 値の範囲 |
|---|---|---|
| c | 記憶セルの番号（下付き添字） | — |
| g⁽ᵗ⁾ | 入力ノード：記憶セルに入れる候補の値 | φ（tanh）なので −1〜1 |
| i⁽ᵗ⁾ | 入力ゲート：g をどれだけ通すか | σ なので 0〜1 |
| f⁽ᵗ⁾ | 忘却ゲート：前の内部状態をどれだけ残すか | 0〜1 |
| o⁽ᵗ⁾ | 出力ゲート：内部状態をどれだけ出力するか | 0〜1 |
| s⁽ᵗ⁾ | 内部状態（セル状態）。s_c はセル c の値 | 制限なし（線形） |
| h⁽ᵗ⁾ | 隠れ層の出力（各記憶セルの出力を並べたベクトル） | −1〜1 |
| v_c | 記憶セル c が最終的に出す値 | — |
| W^gx, W^gh など | 入力 x・前時刻の h から各ゲートへの重み | (d_h, d_x), (d_h, d_h) |
| b_g, b_i, b_f, b_o | 各ゲートのバイアス | (d_h,) |
| ⊙ | 要素ごとの積 | — |

$$
\begin{aligned}
s^{(t)} &= g^{(t)} \odot i^{(t)} + s^{(t-1)} \odot f^{(t)}\
h^{(t)} &= \phi(s^{(t)}) \odot o^{(t)}
\end{aligned}
$$

p.20 の s⁽ᵗ⁾ の式は誌面で i⁽ⁱ⁾ と印刷されているが、i⁽ᵗ⁾ の誤植と考えられる（p.18 の同じ式は i⁽ᵗ⁾）。
