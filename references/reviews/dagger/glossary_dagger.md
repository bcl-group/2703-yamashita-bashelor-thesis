## 1. 問題設定

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ imitation learning | 模倣学習 | 手本（エキスパート）の行動を真似るように方策を学習すること。報酬ではなく「この状態ではこう動く」という教師データから学ぶ | p.627 左段 §1 第1段落 |
| ★ sequential prediction | 逐次予測 | 予測を順番に何度も行い、前の予測が次の入力に影響する問題 | p.627 左段 Abstract |
| structured prediction | 構造化予測 | 出力が単語の文字列のように、互いに関係する複数の要素からなる予測問題 | p.628 左段 第3段落 |
| ★ i.i.d. assumption | i.i.d. 仮定（独立同分布の仮定） | 学習データとテストデータの各例が、同じ分布から独立に取られているという仮定。逐次予測では、学習器の予測が将来の入力を変えるので成り立たない | p.627 右段 第1段落 |
| ★ policy π | 方策 | 状態（観測）を受け取って行動を返す関数。この論文では制御器・分類器・回帰器とほぼ同じ意味 | p.627 Abstract、p.628 左段 §2 |
| ★ expert π* | エキスパート | 手本になる方策。人間の操縦者や、ゲームの内部状態を全部知る計画アルゴリズムなど | p.628 右段 第1段落 |
| ★ stationary / non-stationary policy | 定常 / 非定常な方策 | 定常は時刻によらず同じ関数を使う方策。非定常は時刻ごとに別の方策を使う（前向き学習） | p.627 Abstract、p.627 右段 第3段落 |
| ★ deterministic / stochastic policy | 決定的 / 確率的な方策 | 決定的は同じ状態なら必ず同じ行動を返す方策。確率的はくじ引きで行動を選ぶ（SMILe、SEARN の方策の混合） | p.627 Abstract |
| task horizon T | ホライズン（タスクの長さ） | 方策を何ステップ実行するか | p.628 左段 §2 第4段落 |
| ★ induced distribution of states | 方策が引き起こす状態の分布 | その方策を実行したときに訪れる状態の分布。学習する方策自体によって変わる | p.628 右段 第2段落 |
| immediate cost C(s, a) | 即時コスト | 状態 s で行動 a をとったときのコスト。[0, 1] に有界と仮定する | p.628 左段 §2 第4段落 |
| ★ cost-to-go J(π) | 総コスト（残りのコスト） | 方策を T ステップ実行したときのコストの合計 | p.628 左段 §2 第4段落 |
| ★ surrogate loss ℓ | 代理損失 | 本当のコスト C の代わりに最小化する、観測できる損失。エキスパートとの行動のずれ（0-1 損失、二乗損失など） | p.628 右段 第1段落 |
| 0-1 loss | 0-1 損失 | 行動がエキスパートと一致すれば 0、違えば 1 とする損失 | p.628 右段 第1段落 |
| hinge loss | ヒンジ損失 | SVM で使う損失。正しい側に十分な余裕（マージン）があれば 0、なければ線形に増える | p.628 右段 第1段落 |
| non-convex objective | 非凸な目的関数 | 局所最適解が複数ありうる目的関数。ここでは、データの分布が方策に依存するせいで、損失自体が凸でも目的関数が非凸になる | p.628 右段 第3段落 |

## 2. 既存手法

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ supervised approach | 教師ありアプローチ | エキスパートが訪れた状態だけで学習する従来の方法（式(2)）。行動のクローン（behavior cloning）とも呼ばれる（この論文ではその名前は使わない） | p.628 右段 §2.1 |
| ★ compounding of errors | 誤差の積み重なり（雪だるま式の誤差） | 一度間違えると手本にない状態に入り、さらに間違えやすくなること。総コストが T² に比例して増える原因 | p.627 右段 第2段落 |
| tight bound | タイトな上界 | 実際にその値に達する例があり、これ以上改善できない上界 | p.628 右段 第6段落 |
| forward training | 前向き学習 | 時刻 t の方策を、それまでの方策が作る時刻 t の状態分布で順に学習する方法。T 個の方策が必要で、途中で止められない | p.629 左段 §2.2 |
| SMILe | 確率的混合反復学習 | 反復ごとに新しい方策を混合に少しずつ加え、エキスパートの割合を (1−α)ⁿ に減らしていく方法。方策は確率的 | p.629 右段 §2.3 |
| SEARN | （サーン） | Daumé III et al.（2009）の構造化予測の手法。SMILe と同じく方策の確率的な混合を反復で更新する | p.627 右段 第3段落 |
| CPI | 保守的方策反復 | Kakade and Langford（2002）の強化学習の手法。方策を少しずつ混ぜて更新する | p.627 右段 第3段落 |
| policy iteration | 方策反復 | 方策の評価と改善を交互に繰り返す方法。SEARN の α = 1 はこれにあたり、不安定になりうる | p.633 右段 第1段落 |
| u（定理 2.2） | 1 回のずれによるコスト増加の上界 | 1 回だけエキスパートと違う行動をとり、その後エキスパートに戻したとき、残りのコストが最大どれだけ増えるか | p.629 左段 定理 2.2 |
| mixing（α-mixing） | 混合（α 混合） | マルコフ連鎖で初期状態の影響が時間とともに忘れられる性質。速く混合するなら u は O(1) | p.629 脚注2 |
| MDP | マルコフ決定過程 | 次の状態が現在の状態と行動だけで確率的に決まる意思決定の枠組み | p.629 脚注2 |

## 3. DAgger

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ DAgger (Dataset Aggregation) | データセット集約 | 学習中の方策で軌道を集め、訪れた状態にエキスパートのラベルを付けてデータセットに足し、全データで学習し直すことを繰り返す方法 | p.629 右段 §3、p.630 アルゴリズム 3.1 |
| ★ aggregate | 集約する | 過去の反復で集めたデータを捨てず、すべて合わせて使うこと（D ← D ∪ Dᵢ） | p.630 アルゴリズム 3.1 |
| ★ β_i | 混合率 | 反復 i でデータを集めるとき、各ステップでエキスパートの行動を使う確率。β_i = I(i = 1) が最も簡単な版 | p.630 左段 第2・3段落 |
| indicator function I(·) | 指示関数 | 条件が真なら 1、偽なら 0 を返す関数 | p.630 左段 第3段落 |
| meta-algorithm | メタアルゴリズム | 中で使う学習アルゴリズム（分類器・回帰器）を自由に選べる、外側の手順 | p.628 左段 第2段落 |
| ★ reduction | 帰着 | ある問題を解き方の分かっている別の問題に置き換え、その性能保証を元の問題の保証に変換すること。ここでは模倣学習を後悔なしオンライン学習に置き換える | p.628 左段 第2段落 |
| base learner | 基本の学習器 | DAgger の中で使う教師あり学習器。実験では線形回帰や線形 SVM | p.632 左段 §5.1 |
| validation | 検証 | 学習に使わないデータで、反復で得られた方策の中から最良のものを選ぶこと | p.630 アルゴリズム 3.1 |

## 4. オンライン学習と理論

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ online learning | オンライン学習 | 毎回答えを出し、そのあと損失を見て次の答えを決める、を繰り返す学習の枠組み。損失関数は毎回変わってよい | p.630 右段 §4.1 |
| ★ regret | 後悔 | 実際に出した答えの列の損失と、後から見て最良の固定の答えの損失の差 | p.631 左段 式(3) |
| ★ no-regret algorithm | 後悔なしアルゴリズム | 平均の後悔 γ_N が N → ∞ で 0 に近づくアルゴリズム | p.631 左段 式(3) |
| adversarial | 敵対的 | 損失関数がアルゴリズムを困らせるように選ばれる最悪の状況 | p.631 左段 第1段落 |
| ★ Follow-The-Leader (FTL) | フォロー・ザ・リーダー | 毎回、それまでのすべての損失の合計を最小にする答えを選ぶアルゴリズム。DAgger はこれにあたる | p.628 左段 第2段落、p.630 左段 第1段落 |
| best policy in hindsight | 後から見て最良の方策 | すべての反復の損失を知ったうえで選ぶ、1 つの固定の方策 | p.630 左段 第3段落 |
| strongly convex | 強凸 | 2 次関数以上に下に凸であること。最小値が一意で、オンライン学習の後悔が Õ(1/N) で減る | p.630 左段 第3段落 |
| total variation distance | 全変動距離 | 2 つの確率分布の違いの大きさ。ここでは L1 ノルム ‖p − q‖₁ で書き、値は 0〜2 | p.631 左段 第3段落 |
| error reduction assumption | 誤差帰着の仮定 | どんな入力分布に対しても、代理損失 ε を達成する方策がクラス Π の中にあるという仮定 | p.631 右段 第1段落 |
| online-to-batch | オンラインからバッチへの変換 | オンライン学習の後悔の保証を、ふつうの（バッチの）汎化誤差の保証に変える技法 | p.628 左段 第3段落 |
| sample complexity | 標本複雑度 | 目標の精度を得るのに必要なデータ（軌道）の量 | p.628 左段 第3段落 |
| finite sample case | 有限サンプルの場合 | 各反復で軌道を有限本（m 本）しか集められない場合 | p.630 右段 第2段落、p.631 右段 第2段落 |
| martingale | マルチンゲール | 各ステップの増分の、過去で条件付けた期待値が 0 になる確率過程。独立でなくても使える集中不等式がある | p.631 右段 定理 4.2 の証明 |
| Azuma-Hoeffding's inequality | アズマ・ヘフディングの不等式 | 増分が有界なマルチンゲールの和が、期待値から大きくずれる確率を exp(−t²/(2nc²)) で抑える不等式 | p.630 右段 第2段落 |
| Bernoulli's inequality | ベルヌーイの不等式 | (1 − β)ᵀ ≥ 1 − βT（β ∈ [0, 1]）。補題 4.1 の最後で使う（論文には名前は出ない） | p.631 左段 補題 4.1 の証明 |
| Õ(·) | ソフトオー | 対数の因子を無視したオーダー。T log T も Õ(T) | p.630 左段 定理 3.1 |
| generalization error | 汎化誤差 | 学習データでの損失と、真の分布での損失の差 | p.632 左段 第1段落 |
