## 図1 人工ニューロン（p.7）

- **何を表すか**：1つのニューロン（緑の楕円）が、4つの入力 $x_1, \ldots, x_4$（青）から値を受け取って計算する様子
- **図から分かる事実**
    - 下の $\Sigma$ で重み付き和 $a_j = \sum_{j'} w_{jj'} x_{j'}$ を計算する
    - 上の $\sigma$ でシグモイド $\sigma(a_j) = 1/(1 + e^{-a_j})$ をかけて出力する
- **主張**：ニューロンの計算は「重み付き和 → 活性化関数」の2段階である
- **指差す場所**：$\Sigma$ → $\sigma$ → 上向きの矢印
- **注意**：本文の式では入力の値を $v_{j'}$、活性化関数を一般の $l_j$ と書いているが、図では $x_{j'}$ と $\sigma$ になっている
- 📍 p.7 図1、p.6 §2.2

## 図2 順伝播型ニューラルネットワーク（p.8）

- **何を表すか**：入力4個（青）、隠れ層3個（緑）、出力1個（赤）の順伝播型ネットワーク
- **図から分かる事実**
    - 入力の各ノードは隠れ層の全ノードに、隠れ層の各ノードは出力につながっている（全結合）
    - 矢印は下から上への一方向だけで、ループがない
- **主張**：循環がないので、下の層から順に計算できる。入力を最下層に与え、最上層で出力を得る
- **指差す場所**：入力 → 隠れ層 → 出力の順
- 📍 p.8 図2、§2.3 第1–2段落

## 図3 単純な再帰型ネットワーク（p.11）

- **何を表すか**：入力1個、隠れノード2個、出力1個の RNN
- **図から分かる事実**
    - 実線：入力 → 隠れ層 → 出力。同じ時刻の中の計算で、順伝播型と同じ
    - ピンクの破線：次の時刻への結合。4本ある
        - 各隠れノードから自分自身へ（自己結合）：2本
        - 隠れノードどうし、互いに：2本
- **主張**：RNN は、順伝播型ネットワークに「次の時刻へつなぐ破線の辺」を加えたものである
- **式との対応**：破線4本は、2×2 の重み行列 $W^{\mathrm{hh}}$ の4つの要素にあたる

$$
\boldsymbol{h}^{(t)} = \sigma\left( W^{\mathrm{hx}} \boldsymbol{x}^{(t)} + W^{\mathrm{hh}} \boldsymbol{h}^{(t-1)} + \boldsymbol{b}_h \right)
$$

- **指差す場所**：実線（入力→隠れ層＝$W^{\mathrm{hx}}$、隠れ層→出力＝$W^{\mathrm{yh}}$）→ 破線（$W^{\mathrm{hh}}$）
- 📍 p.11 図3、p.10 §3

## 図4 図3を時間方向に展開したもの（p.12）

- **何を表すか**：図3の RNN を、時刻 $t = 1$ と $t = 2$ の2時刻分、横に並べたもの
- **図から分かる事実**
    - 各時刻に、入力・隠れ層・出力の同じ構造が1つずつある
    - 図3でループだった破線が、$t = 1$ の隠れノードから $t = 2$ の隠れノードへの破線（4本）になっている
    - ループがなくなり、すべての矢印が下から上、左から右に流れる
- **主張**：展開すると、RNN は「1時刻につき1層を持ち、全時刻で重みを共有する深い順伝播型ネットワーク」とみなせる。そのため誤差逆伝播法が使える（BPTT）
- **指差す場所**：図3の自己結合のループと、図4の $t=1$ → $t=2$ の破線を見比べる
- **補足説明に使える図**：`figures/bptt_unrolled.svg`（各矢印に重みの記号を付けた図）
- 📍 p.12 図4、p.11 第2段落

## 図5 Jordan ネットワーク（p.13）

- **何を表すか**：Jordan（1986）の RNN。入力4個、隠れ層3個、出力3個、文脈ユニット3個（黄色）
- **図から分かる事実**
    - 青い太線（重み1に固定）：**出力**の各ノードから、対応する文脈ユニットへ。出力の値をそのままコピーする
    - 文脈ユニットの破線のループ：自己結合。次の時刻の自分自身へ
    - 文脈ユニットから隠れ層への破線：次の時刻の隠れ層へ送る
- **主張**：Jordan ネットワークは、**前の時刻の出力**を覚えておき、次の時刻の計算に使う。自己結合により、さらに前の出力も少しずつ残る
- **指差す場所**：出力 → 青い太線 → 黄色の文脈ユニット → ループ → 破線で隠れ層へ
- **注意**：キャプションでは文脈ユニットを "special units" と呼んでいる。脚注2で「context units」に統一すると書いている
- 📍 p.13 図5、p.12 第1段落・脚注2

## 図6 Elman ネットワーク（p.14）

- **何を表すか**：Elman（1990）の RNN。構成は図5と同じ（入力4、隠れ3、出力3、文脈3）
- **図から分かる事実**
    - 青い太線（重み1に固定）：**隠れ層**の各ノードから、対応する文脈ユニットへ
    - 文脈ユニットから隠れ層への破線：次の時刻の隠れ層へ戻す
    - 文脈ユニットに**自己結合のループがない**（図5との違い）
- **主張**：Elman ネットワークは、**前の時刻の隠れ層**をそのままコピーして次の時刻に使う。これは §3 の単純 RNN と同じ働きである。重み1に固定した結合で値を保つ考えは、LSTM の基礎になった
- **図5との比べ方**：青い太線が「出力から」出ているか（図5）、「隠れ層から」出ているか（図6）。文脈ユニットにループがあるか（図5）、ないか（図6）
- 📍 p.14 図6、p.12 第2段落

## 図7 最も簡単な再帰型ネットワーク（p.15）

- **何を表すか**：入力1個、隠れノード1個、出力1個で、隠れノードが自己結合（ピンクの破線）を1本だけ持つ RNN
- **図から分かる事実**：再帰の重みは、自己結合の1つ $w_{jj}$ だけである
- **主張**：勾配消失・爆発を説明するための、最小のおもちゃのモデル
- 📍 p.15 図7、p.13 §3.2

## 図8 勾配消失の可視化（p.15）

- **何を表すか**：図7のネットワークを4時刻分展開したもの。Graves（2012）の図を改変している
- **図から分かる事実**
    - 入力は、最初の時刻だけ濃い青で、残りは白（入力なし）
    - 隠れノードの緑は、時刻が進むにつれて**濃い緑 → 薄い緑**へと薄くなる
    - 色の濃さは、最初の時刻の入力がそのノードにどれだけ影響しているか（感度）を表す
- **主張**：再帰辺の重みが1より小さいと、最初の入力が最後の出力に与える影響は、時間間隔の長さに対して指数的に小さくなる。逆向きに見れば、最後の誤差は最初の時刻にほとんど届かない（勾配消失）
- **数値で補足**：重み 0.5 なら、1時刻ごとに約半分になる（$0.5 \to 0.25 \to 0.125$）。100時刻で $0.5^{100} \approx 10^{-30}$
- **指差す場所**：左の濃い緑から右の薄い緑へ、指でなぞる
- 📍 p.15 図8、p.14 第1段落

## 図9 LSTM の記憶セル（元の LSTM, p.17）

- **何を表すか**：Hochreiter and Schmidhuber（1997）の、記憶セル1つの内部構造（水色の四角）
- **図の記号**
    - 斜線の入った丸：線形のノード（内部状態 $s_c$）
    - $\sigma$ の丸：シグモイドのノード
    - $\Pi$ の丸：入力の積を出力するノード（掛け算）
    - 青い破線のループ：内部状態の自己結合。重みは1に固定
    - 点線（Edge from previous time step）：前の時刻の隠れ層と現在の入力から入ってくる結合
- **図から分かる事実**（下から上へ）
    1. 入力ノード $g_c$（一番下の $\sigma$）が、入力と前の時刻の隠れ層から値を受け取る
    2. 下の $\Pi$ で、$g_c$ に入力ゲート $i_c$（右下の $\sigma$）を掛ける
    3. 内部状態 $s_c$ に足し込む。内部状態は、前の時刻の自分の値も重み1で受け取る：$s_c^{(t)} = g_c^{(t)} \cdot i_c^{(t)} + s_c^{(t-1)}$
    4. 上の $\Pi$ で、$s_c$ に出力ゲート $o_c$（右上の $\sigma$）を掛けて出力する：$v_c^{(t)} = s_c^{(t)} \cdot o_c^{(t)}$
- **主張**：内部状態が重み1の自己結合を持つので、値も誤差も、減りも増えもせずに多くの時刻を通過できる（定誤差カルーセル）。ゲートは「入れるか」「出すか」を掛け算で制御する
- **指差す場所**：青い破線のループ（ここが勾配消失を防ぐ核心）→ 2つの $\Pi$
- **注意**：図の出力の式 $v_c = s_c \cdot o_c$ には tanh がないが、p.20 の式は $\boldsymbol{h} = \phi(\boldsymbol{s}) \odot \boldsymbol{o}$ と tanh をかけている
- 📍 p.17 図9、p.18 箇条書き

## 図10 忘却ゲート付きの記憶セル（p.19）

- **何を表すか**：Gers et al.（2000）の、忘却ゲートを加えた記憶セル
- **図から分かる事実**
    - 図9に、左の $\sigma$（忘却ゲート $f_c$）と、左の $\Pi$ が加わっている
    - 内部状態の自己結合が、そのまま戻るのではなく、左の $\Pi$ で $f_c$ を掛けられてから戻る：$s_c^{(t)} = g_c^{(t)} \cdot i_c^{(t)} + s_c^{(t-1)} \cdot f_c^{(t)}$
- **主張**：忘却ゲートが0に近いと、内部状態の中身を消去できる。動き続けるネットワークで、古い記憶をリセットするのに役立つ
- **図9との比べ方**：左側の $f_c$ と $\Pi$ だけが違う
- **注意**：図中の式も $i_c^{(i)}$ になっていて、p.20 の式と同じ誤植がある（正しくは $i_c^{(t)}$）
- 📍 p.19 図10、p.18 箇条書き「Forget gate」

## 図11 記憶セル2つの隠れ層（p.20）

- **何を表すか**：隠れ層が記憶セル2つからなる RNN を、2時刻分展開したもの。入力1個、出力1個
- **図から分かる事実**
    - 各時刻に記憶セル（水色の四角）が2つ並ぶ
    - 入力は、両方のセルの入力ノードとすべてのゲートにつながる
    - ピンクの破線：前の時刻の各セルの出力が、次の時刻の**両方の**セルの入力ノードと**すべての**ゲートに入る
- **主張**：記憶セルは、単純 RNN の隠れノード1個を置き換える部品である。セルどうしは、単純 RNN の隠れノードどうしと同じように、次の時刻へ全結合でつながる（図4に対応）
- **説明のコツ**：線が多くて複雑なので、細部は追わず、「図4の緑の丸が水色の四角に置き換わった」とだけ言う
- 📍 p.20 図11、p.21 第2段落

## 図12 双方向 RNN（BRNN, p.21）

- **何を表すか**：Schuster and Paliwal（1997）の BRNN を、3時刻分（$t-1$, $t$, $t+1$）展開したもの
- **図から分かる事実**
    - 隠れノードが各時刻に2段ある
        - 上の段：ピンクの破線で**右向き**（次の時刻へ）。過去から未来へ情報を運ぶ
        - 下の段：水色の破線で**左向き**（前の時刻へ）。未来から過去へ情報を運ぶ
    - 入力は両方の段に、両方の段が出力につながる
- **主張**：各時刻の出力を、過去の情報（上の段）と未来の情報（下の段）の両方から決められる
- **指差す場所**：ピンクの破線を右へ、水色の破線を左へなぞる → 真ん中の出力に両方が入ることを示す
- **注意**：この図だけ入力を $\boldsymbol{x}_{t-1}$、$\boldsymbol{x}_t$ と**下付き**で書いていて、論文自身の約束（時刻は上付きの括弧）と食い違う
- 📍 p.21 図12、§4.2

## 図13 RNN による入出力の形（p.24）

- **何を表すか**：RNN で扱える入出力の5つの形。Karpathy（2015）の図がもと
    - 青：入力、赤：出力、緑：ネットワークの隠れ状態全体
- **図から分かる事実**

| | 形 | 例 |
|---|---|---|
| (a) | 1入力 → 1出力 | 標準的な順伝播型（独立な場合） |
| (b) | 系列 → 1出力 | 文章・動画の分類 |
| (c) | 1入力 → 系列 | 画像キャプション生成 |
| (d) | 系列 → 系列（入力を読み終えてから出力。長さが違ってよい） | 翻訳 |
| (e) | 系列 → 系列（各時刻に出力） | 次の文字を予測する文章生成 |

- **主張**：RNN は、系列の入力・系列の出力・その両方を、同じ枠組みで扱える
- **(d) と (e) の見分け方**：(d) は入力をすべて読んでから出力が始まる。(e) は入力と出力が各時刻で対応する
- **自分の研究との関係**：基本は (b)。初期状態を符号化器で隠れ状態にする点が加わる
- 📍 p.24 図13

## 図14 sequence to sequence の LSTM（p.28）

- **何を表すか**：Sutskever et al.（2014）の英→仏翻訳モデル。英語 "My feet hurt" をフランス語 "J'ai mal aux pieds" に訳す例
- **図から分かる事実**
    - 左の緑（LSTM1）：符号化器。英語の単語を1つずつ読む。この間は何も出力しない
    - 右の水色（LSTM2）：復号器。文の区切り記号 `<EOS>` を合図に、フランス語を1単語ずつ出力する
    - 復号器の入力（紫）は、1つ前に出力した単語である（"J'ai" を出したら、次の入力は "J'ai"）
    - `<EOS>` を出力したら終わる
- **主張**：入力と出力で長さが違う系列（3単語 → 4単語）でも、符号化器と復号器に分けることで変換できる。図13の (d) にあたる
- **ほかの節とのつながり**：出力を次の入力に戻す仕組みは、図5の Jordan ネットワークの発想と同じ
- **注意**：本文（p.27）では「入力文を**逆順**に入れると結果が大きく改善した」とあるが、図では入力が正順（My feet hurt）で描かれている
- 📍 p.28 図14、p.27 §5.3

# 第2部 評価指標

## 1. そもそも何を測りたいのか

- 分類なら「正解か不正解か」で測れる
- 翻訳やキャプションでは、正解が1つに決まらない
    - 例：「猫がマットの上にいる」と「マットの上に猫がいる」はどちらも正しい
- そこで、人が作った**参照訳**（正解の例。複数あることが多い）と、モデルが出した**候補訳**が、どれだけ似ているかを数える
- 📍 p.25 §5.2、p.26 冒頭

## 2. 基本の道具：適合率と再現率

| 指標 | 意味 | 式 |
|---|---|---|
| 適合率（precision）$P$ | 候補訳の単語のうち、参照訳にもある割合。「余計なことを言っていないか」 | 一致した単語数 ÷ 候補訳の単語数 |
| 再現率（recall）$R$ | 参照訳の単語のうち、候補訳に含まれる割合。「言うべきことを言えているか」 | 一致した単語数 ÷ 参照訳の単語数 |
| F 値 | 両者のバランス（調和平均） | $F_1 = \dfrac{2PR}{P + R}$ |

**例**：参照訳「the cat is on the mat」（6語）、候補訳「the cat on the mat」（5語）

$$
P = \frac{5}{5} = 1.0, \qquad R = \frac{5}{6} = 0.833
$$

候補訳は余計なことを言っていない（$P = 1$）が、「is」が抜けている（$R < 1$）。

## 3. BLEU（Papineni et al., 2002）

### 考え方
- 候補訳の **$n$ グラム**（連続する $n$ 単語のまとまり）が、参照訳にどれだけ現れるかを数える
    - 1グラム：単語が正しいか
    - 2グラム以上：語順が正しいか
- 適合率だけを使い、再現率の代わりに**短さペナルティ**を使う

### 手順
**① 修正 $n$ グラム適合率 $p_n$**

$$
p_n = \frac{\text{参照訳に現れる、候補訳の } n \text{ グラムの数}}{\text{候補訳の } n \text{ グラムの総数}}
$$

「修正」と呼ぶのは、参照訳が複数ある場合に合わせて普通の適合率を変えているため（p.26）。
元の BLEU では、同じ単語を数えすぎないように、参照訳に出てくる回数を上限にして数える（クリッピング）。例：候補訳「the the the the」は、参照訳に「the」が2回しかないので $p_1 = 2/4$。論文はこの点を省いている

**② 幾何平均**：$n = 1$ から $N$（普通は4）までの $p_n$ を、掛け合わせて $N$ 乗根をとる

$$
\exp\left( \frac{1}{N} \sum_{n=1}^{N} \log p_n \right) = \left( p_1 p_2 \cdots p_N \right)^{1/N}
$$

幾何平均を使うので、どれか1つの $p_n$ が0だと全体が0になる

**③ 短さペナルティ $B$**：適合率だけだと、自信のある1語だけ出せば $P = 1$ になってしまう。そこで、候補訳が参照訳より短いと罰する。$c$ は候補訳の長さ、$r$ は参照訳の長さ

$$
B = \begin{cases} 1 & (c > r) \\ e^{(1 - r/c)} & (c \le r) \end{cases}
$$

**④ BLEU スコア**

$$
\mathrm{BLEU} = B \cdot \exp\left( \frac{1}{N} \sum_{n=1}^{N} \log p_n \right)
$$

### 数値例（参照訳「the cat is on the mat」、候補訳「the cat on the mat」）

| $n$ | 候補訳の $n$ グラム | 参照訳に現れるもの | $p_n$ |
|---|---|---|---|
| 1 | the, cat, on, the, mat | 5個 | $5/5 = 1$ |
| 2 | the cat, cat on, on the, the mat | the cat, on the, the mat | $3/4 = 0.75$ |
| 3 | the cat on, cat on the, on the mat | on the mat | $1/3$ |
| 4 | the cat on the, cat on the mat | なし | $0$ |

$$
B = e^{(1 - 6/5)} = e^{-0.2} = 0.819
$$

- $N = 2$ なら：$0.819 \times (1 \times 0.75)^{1/2} = 0.819 \times 0.866 = 0.709$
- $N = 4$ なら：$p_4 = 0$ なので **BLEU = 0**

「is」が1語抜けただけのほぼ正しい訳でも、1文単位では0になる。実際には、多数の文で $n$ グラムの数を合計してから計算する（コーパス単位）ので、0にはなりにくい。

### 長所と限界
- 長所：計算が簡単。$N = 4$ で、大量の訳の集合では人間の評価とよく相関する
- 限界
    - 1文単位では人間の判断を正確に予測できない
    - BLEU が高い訳のほうが良いという保証はない
    - 同義語を区別できない（「big」と「large」は不一致になる）
- 📍 p.26 第1–2段落

## 4. METEOR（Banerjee and Lavie, 2005）

### 考え方
- BLEU の弱点を補うため、候補訳と参照訳の単語を**1対1で対応付け**る
- 完全一致に加えて、**語幹**（「sits」と「sitting」）や**同義語**（「big」と「large」）も一致とみなす
- 再現率も使う。語順の崩れは「断片化ペナルティ」で罰する
- 参照訳が複数あるときは、最も良いスコアを使う

### 手順
**① F 値**：単語の一致から $P$ と $R$ を求め、重み $\alpha$ 付きの F 値を計算する

$$
F_\alpha = \frac{P \cdot R}{\alpha \cdot P + (1 - \alpha) \cdot R}
$$

$\alpha = 0.5$ なら普通の $F_1$ になる。元の METEOR では $\alpha = 0.9$ として、再現率を重視している（$F = 10PR / (R + 9P)$。これは論文には書かれていない）

**② 断片化ペナルティ $M$**：$M \propto c/m$
- $c$：候補訳と参照訳の両方で単語が連続している「かたまり（chunk）」の最小数
- $m$：一致した単語の総数
- 語順が参照訳と同じなら、かたまりは1つで $c$ が最小になる。語順がばらばらだと、かたまりが細かく分かれて $c$ が大きくなる
- 元の METEOR では $M = 0.5 \times (c/m)^3$（これも論文には書かれていない）

**③ スコア**

$$
\mathrm{METEOR} = (1 - M) \cdot F_\alpha
$$

### 数値例（同じ例）
- 一致：$m = 5$、$P = 1.0$、$R = 0.833$
- かたまり：「the cat」と「on the mat」の2つ。どちらも両方の文で連続している。$c = 2$
- 元の METEOR の式で計算すると
    - $F = \dfrac{10 \times 1.0 \times 0.833}{0.833 + 9 \times 1.0} = \dfrac{8.33}{9.833} = 0.847$
    - $M = 0.5 \times (2/5)^3 = 0.5 \times 0.064 = 0.032$
    - $\mathrm{METEOR} = (1 - 0.032) \times 0.847 = 0.820$

BLEU（$N = 4$）では0だった同じ訳が、METEOR では 0.82 と、人間の感覚に近い値になる。

### 長所と限界
- 長所：BLEU より人間の評価とよく一致する
- 限界：計算が複雑。他者のスコアを再現するには、語幹処理・同義語の辞書・計算方法をすべて同じにする必要がある
- 📍 p.26 第3段落、p.27 第1段落

## 5. BLEU と METEOR の比較

| | BLEU | METEOR |
|---|---|---|
| 基本 | $n$ グラムの適合率 | 単語の対応付けによる F 値 |
| 再現率 | 使わない（短さペナルティで代用） | 使う（重視する） |
| 語順 | 2グラム以上の一致で間接的に | 断片化ペナルティで直接 |
| 同義語・語幹 | 扱わない | 扱う |
| 1文単位の評価 | 苦手 | BLEU よりは良い |
| 計算・再現 | 簡単 | 難しい |
| 共通の前提 | 参照訳の集合がまったく同じでないと比較できない | 同左 |

## 6. 著者らの懸念（論文の主張）

- 系列のない2値分類でさえ、F1 のようなよく使う指標では、最適な閾値の決め方が「よい性能」の直感と合わないことがある（Lipton et al., 2014）
- BLEU や METEOR は、本当の目的（良い翻訳）の**弱い代理**にすぎない
- そのため、本当に強いシステムと、使われている指標に過学習しただけのシステムを区別しにくい
- §6 の提言：新しい技術は、まず評価の確立した課題（順伝播型ネットワークの標準的なデータセット）で試すべきである
- 📍 p.27 第2段落、p.31 §6 第3段落

## 7. 自分の研究に置き換えると（推測）

- 膜電位の予測では、Spiking systems 論文と同様に、時刻ごとの誤差（L1 ノルム）で学習・評価する
- しかし、BLEU と同じ問題が起こりうる。スパイクの形がほぼ正しくても、タイミングが少しずれるだけで、各時刻の誤差は大きくなる
- そのため、時刻ごとの誤差に加えて、スパイクのタイミングやスパイク数の一致など、スパイク列としての類似度も見る必要がある。これは論文の「指標は本当の目的の弱い代理」という指摘と同じ構図である

## 8. 元論文の注意点
- BLEU の $c$（候補訳の平均の長さ）と METEOR の $c$（かたまりの数）は、同じ文字で別の量を表している
- METEOR の $M$ は「$c/m$ に比例する」とだけ書かれていて、具体的な式がない
- BLEU のクリッピング（同じ単語を数えすぎない処理）の説明がない
