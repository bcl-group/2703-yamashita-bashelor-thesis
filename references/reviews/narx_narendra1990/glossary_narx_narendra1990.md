## 3. ニューラルネットワーク

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|

| recurrent network | 再帰型ネットワーク | 出力を時間遅れで入力に戻すネットワーク。非線形な力学系になる | p.4 右段 第2段落、p.8 左段 §III-B |
| Hopfield network | ホップフィールド・ネットワーク | 1 層のネットワークをフィードバックに入れた再帰型ネットワーク。平衡状態を記憶に使う | p.8 左段 第5段落、図4・図5 |
| associative memory | 連想記憶 | 初期値の近くの平衡状態に収束することで、記憶したパターンを呼び出す仕組み | p.8 右段 第1段落 |

## 4. 学習（パラメータの調整）

| 用語 | 日本語 | 説明 | 📍初出 |
|---|---|---|---|
| ★ static back propagation | 静的な誤差逆伝播 | フィードバックのないネットワークの勾配を求める通常の誤差逆伝播。series-parallel model ならこれで済む | p.4 Abstract、p.10 §IV-A |
| ★ dynamic back propagation | 動的な誤差逆伝播 | フィードバックを含む系で、時間方向の依存も含めて勾配を求める方法。この論文が導入した用語。parallel model の学習に必要 | p.4 右段 第3段落、p.10 右段 §IV-B |

| diagrammatic representation | 図式表現 | 誤差逆伝播の計算をブロック線図で表したもの（図7）。動的な場合に拡張しやすい | p.10 左段 §IV-A |
| Jacobian matrix | ヤコビ行列 | ベクトル値関数の偏微分を並べた行列。式(12)の Φ_x、Ψ_x、式(13)の ∂N/∂v | p.11 左段 第1段落 |
| nominal trajectory | 名目の軌道 | 線形化の基準にする、現在のパラメータでの軌道 | p.11 左段 第1段落 |
