# 条件を揃えた比較（2026-11-24）

最終候補の比較では、分野ごとに試した量（A は 50 回、B 8 回、C 10 回、D 22 回）、学習の長さ（A・C は 11 万回、B・D は 2 万回）、
出発点（B は古い mm_rel から）がそろっていなかった。ここでは A・C の第 9 ラウンドの作り方（苦手な電流 v2 を半分）に B と D を合わせ、
seed 3 本ずつで学習し直す。

| 分野 | タグ | 中身 |
|---|---|---|
| A | r9_mlp_v2f05d_s0〜2（既存） | Markov MLP 128×2、11 万回 |
| B | eq_b_s0〜2 | 上の A の各 seed に W_hh = 0 を足して始め、系列（32 ステップ）で 2 万回。在庫の半分は苦手な電流 v2 |
| C | m3_v2f05d_s0〜2（既存） | MLP 3 個 128×2、11 万回 |
| D | eq_d_h64_s0〜2、eq_d_h128_s0〜2 | RNN 3 個（並列）、苦手な電流の割合 0.5、6 万回（以前は 2 万回）。H64 と H128 |
