# 条件を揃えた比較（2026-11-24）

最終候補の比較では、分野ごとに試した量（A は 50 回、B 8 回、C 10 回、D 22 回）、学習の長さ（A・C は 11 万回、B・D は 2 万回）、
出発点（B は古い mm_rel から）がそろっていなかった。ここでは A・C の第 9 ラウンドの作り方（苦手な電流 v2 が中心）に B と D を合わせ、
seed 3 本ずつで学習し直す。

| 分野 | タグ | 中身 |
|---|---|---|
| A | r9_mlp_v2f05d_s0〜2（既存） | Markov MLP 128×2、11 万回 |
| B | eq_b_s0〜2 | 上の A の各 seed に W_hh = 0 を足して始め、系列（32 ステップ）で 2 万回 |
| B の対照 | eq_b0_s0〜2 | 同じ A から、W_hh なしで B とまったく同じ系列の学習。B との差が W_hh の効果 |
| C | m3_v2f05d_s0〜2（既存） | MLP 3 個 128×2、11 万回 |

## 苦手な電流の割合を揃える

A・C の `--hard-frac 0.5` は「バッチの半分を苦手な電流から取り、残り半分を全体（苦手な電流が約 3/4）から取る」なので、
実際に見る苦手な電流の状態は 0.5 + 0.5 × 0.75 = 87.5%（DAgger 3 回の後は約 84%、DAgger の状態は約 4%）。

- B: 系列の窓の 85% を苦手な電流（v2、3 s）から取る（`--hard-frac 0.85`）
- D: 新しい軌道を選ぶ重みが 通常 0.35 / 苦手 0.6 / DAgger 0.05。軌道の長さ（通常 300 ms、苦手 3 s、DAgger 1 s）で
  1 本に留まる時間が変わるので、ステップ数の割合は 通常 約 14% / 苦手 約 80% / DAgger 約 7%

採点は検証 17 本（チェックポイントの選択）と開発用 26 本だけ。最終テスト 54 本は使わない（結果を見た後なので、使うと開発用になる）。

## 残っている違い

- B は自分では DAgger を回さない（出発点の A は DAgger 済み）。B の対照 eq_b0 も同じ。
- D の 1 回の更新は 256 本 × 200 ステップの系列で、A・C の 1024 個の状態とは中身が違う。D は途中から短い閉ループの損失も足す。
- 1 版目（2026-11-24 09:12 に開始）は苦手な電流の割合が B 50%、D の DAgger が約 35% と揃っていなかったので、Codex のレビューを受けて止めて、この版でやり直した。
