# 指導案と授業づくりの視点

↑ [[00_ホーム|ホーム]]

## 指導案 細案の書き方（7/23）
細案：1時間分の授業の流れまで詳しく書いた指導案。

### 1. 単元名
- 単元名 ⇐ 小単元の名称（章）

### 2. 本単元について
| 項目 | 書き方 |
|---|---|
| 生徒観 | 「生徒は小学校第○学年で…」。良いこと＋課題も記入 |
| 教材観 | 「〜がねらいである」 |
| 指導観 | 「そこで指導にあたっては、次の点に留意したい。」<br>・……できるようにする。<br>※箇条書きで3点くらい |

### 3. 目標（観点別）
| 観点 | 文末の形 |
|---|---|
| (1) 知識・技能 | 「〜を理解できる」 |
| (2) 思考・判断・表現 | 「〜を説明できる」 |
| (3) 学びに向かう力、人間性等 | 「〜しようとする」 |

### 4. 単元計画（全○時間）
- 第一次　○○○（節）… □時間
- 第二次　△△△（節）… ☆時間（本時 ●/☆）
- ⋮

### 5. 本時案
1. **主眼**：本時の目標。「〜できる」「〜できるようにする」
2. **準備**
3. **学習の展開**（3列で書く）

   | 左 | 中 | 右 |
   |---|---|---|
   | 学習内容・学習活動<br>（生徒が）〜する | 予想される生徒の反応 | 指導上の留意点<br>（指導者が生徒に）…させる<br>（指導者は、生徒が…できるように○○する） |

4. **評価の観点と方法**：主眼「〜できる」について、…でみとる

### 予想される生徒の反応で考えること
- 素朴概念（学習前から持っている、科学的には誤りを含む考え）
- 日常生活での経験
- 観察・実験に対する予想や仮説
- 観察・実験の手順
- 安全指導の内容
- 結果の分析
- 考察について

## 授業づくりの視点（7/30）
### 系統的な学習
- スパイラルカリキュラム（同じ内容を学年を追って繰り返し、深めていく教育課程）で、学習内容が発展するように進んでいく
- ※これまでに何を学んでいるのか、この学習の後にどのように発展するのかを押さえる

### 文脈的な学習
- トピックを決めて、その内容に関係する知識や考え方を学習する

### 学習内容に対する素材をどう教材にするか
- 基本は教科書 → 指導書も使える
- 自分が考えさせたい内容の教材になっているか

## 授業を「観る」視点
| 授業者の視点 | | 児童・生徒の視点 |
|---|---|---|
| 授業構成 | 話す「間」のとり方 | 指示に対してどう動くか |
| 発問・質問 | 児童・生徒の意見への対応 | 授業中に他のことに夢中 |
| 身ぶり・手ぶり | 児童・生徒の活動のさせ方 | 授業の核になりそうな子ども（声の大きい子、話し合いの中心） |
| 立ち位置・ふるまい | | 授業に対する意識 |
| | | 何が変化のきっかけになったか |
