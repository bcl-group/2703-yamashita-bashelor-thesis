# 論文単語帳

英語論文で出会った単語を、品詞・意味・例文付きで記録して復習するローカルWebアプリ。

## 使い方

リポジトリ直下で実行する。

1. 辞書をダウンロード（初回のみ。約260MB）

   ```bash
   uv run python 単語帳アプリ/setup_dict.py
   ```

2. 起動する（http://127.0.0.1:5000 がブラウザで自動的に開く）
   - `単語帳アプリ/単語帳.bat`（またはデスクトップのショートカット「論文単語帳」）をダブルクリック
   - またはターミナルで次を実行

     ```bash
     uv run python 単語帳アプリ/app.py
     ```

   黒いウィンドウを閉じると終了する。起動中にもう一度開くと、ブラウザだけが開く。

### 登録
- 英単語を入力して Enter → 品詞ごとの訳が「保存内容」に入る。もう一度 Enter でそのまま保存
- 訳の × で削除、行末の欄で追加（空のまま Enter で保存）。品詞はプルダウンで変更
- 「WordNet の他の訳」「辞書の訳」をクリックすると保存内容に追加できる
- 例文欄は Enter で改行。Ctrl+Enter でどこからでも保存
- 活用形は原形に直して検索する（`Networks,` → `network`）

### 一覧・クイズ
- 一覧: 単語・訳で検索、品詞で絞り込み、行クリックで編集
- クイズ: Space で答え表示、→ で「覚えた」、← で「まだ」。間違いが多い語・しばらく出ていない語ほど出やすい

## データ
- 単語帳: `単語帳アプリ/vocab.json`（git で管理する）
- 辞書: `単語帳アプリ/data/`（git 管理外）

## テスト

```bash
uv run pytest 単語帳アプリ/tests -q
```
