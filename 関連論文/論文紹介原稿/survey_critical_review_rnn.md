### 論文が定式化している一般的な RNN の写像

【学習タスク（一般形）】

```
入力：系列 x⁽¹⁾, x⁽²⁾, …, x⁽ᵀ⁾（各 x⁽ᵗ⁾ は実数ベクトル）
        ↓
ニューラルネットワーク：単純 RNN（または LSTM）
        ↓
出力：系列 ŷ⁽¹⁾, …, ŷ⁽ᵀ⁾（目標系列 y⁽¹⁾, …, y⁽ᵀ⁾ に近づくよう学習）
```
📍出典：p.5 §2.1 第1段落 1–6行目／p.6 第2段落 1–6行目

【学習している写像（単純 RNN）】

$$
h^{(t)} = \sigma\!\left(W^{hx}x^{(t)} + W^{hh}h^{(t-1)} + b_h\right),\qquad
\hat y^{(t)} = \mathrm{softmax}\!\left(W^{yh}h^{(t)} + b_y\right)
$$

📍出典：p.10 第5段落（1つ目の式）／p.11 最上部の式（2つ目の式）／p.11 第1段落 1–4行目（W^hx, W^hh, b_h, b_y の意味）

つまり

$$
\big(x^{(1)}, \dots, x^{(t)}\big) \;\longmapsto\; \hat y^{(t)}
$$

という「現在までの入力系列 → 現在時刻の出力」の写像を、隠れ状態 h⁽ᵗ⁾ を介して学習する。

注意：出力の softmax は分類の場合の例。**回帰では出力層は通常、線形**と書かれている。
📍出典：p.7 第3段落 1–3行目（出力の活性化関数は課題による）、6–7行目（回帰では通常、線形出力）

## 8. ニューラルネットワークの構造（論文が解説するもの）

### 8.1 単純 RNN（Elman 型）

| 項目 | 内容 | 📍出典 |
|---|---|---|
| 定義 | 順伝播型ネットワークに、隣り合う時刻をつなぐ辺（再帰辺）を加えたもの | p.10 第4段落 1–6行目 |
| 式 | h⁽ᵗ⁾ = σ(W^hx x⁽ᵗ⁾ + W^hh h⁽ᵗ⁻¹⁾ + b_h)、ŷ⁽ᵗ⁾ = softmax(W^yh h⁽ᵗ⁾ + b_y) | p.10 第5段落の式／p.11 最上部の式 |
| 図 | 図3（単純 RNN）、図4（時間方向への展開） | p.11 図3／p.12 図4 |
| 展開した見方 | 時刻ごとに1層を持ち、重みを時刻間で共有する深いネットワークとみなせる | p.11 第2段落 1–4行目 |
| Elman ネットワーク | 隠れ層の各ユニットに文脈ユニットを付け、前時刻の隠れ状態を戻す。各隠れノードが自己結合を1本持つ単純 RNN と等価 | p.12 第2段落 1–7行目／p.14 図6 |
| Jordan ネットワーク | 出力ノードの値を特別なユニットに送り、次時刻の隠れ層に入れる | p.12 第1段落 1–5行目／p.13 図5 |

構造図（単純 RNN、図3・図4 に対応）：

```
 x⁽¹⁾      x⁽²⁾      x⁽³⁾
  │ W^hx    │ W^hx    │ W^hx
  ▼         ▼         ▼
 h⁽¹⁾ ───▶ h⁽²⁾ ───▶ h⁽³⁾ ───▶ …     （W^hh：時刻間で共有）
  │ W^yh    │ W^yh    │ W^yh
  ▼         ▼         ▼
 ŷ⁽¹⁾      ŷ⁽²⁾      ŷ⁽³⁾
```
📍出典：p.11 図3／p.12 図4

### 8.2 LSTM

| 項目 | 内容 | 📍出典 |
|---|---|---|
| 目的 | 主に勾配消失問題を克服するため | p.17 §4.1 第1段落 1–2行目 |
| 構造 | 隠れ層の通常のノードを記憶セル（memory cell）に置き換える | p.17 第1段落 3–4行目／p.17 図9 |
| 内部状態 s_c | 線形の活性化を持ち、重み1で固定された自己結合を持つ。誤差が時間をまたいで消失・爆発せずに流れる（constant error carousel） | p.18 箇条書き「Internal state」1–6行目 |
| 入力ノード g | x⁽ᵗ⁾ と h⁽ᵗ⁻¹⁾ を受け取る。通常 tanh、元の論文では sigmoid | p.18 箇条書き「Input node」1–6行目 |
| 入力ゲート i | sigmoid のユニットで、入力ノードの値に掛け算する | p.18 箇条書き「Input gate」1–8行目 |
| 忘却ゲート f | Gers et al.（2000）が導入。内部状態の内容を消すことを学習できる。連続して動き続けるネットワークで特に有用 | p.18 箇条書き「Forget gate」1–4行目 |
| 出力ゲート o | 内部状態（通常 tanh を通す）に掛け算して出力を作る | p.18 箇条書き「Output gate」1–5行目 |
| 忘却ゲートの普及 | 元の LSTM にはなかったが、現在の多くの実装で標準 | p.19 第2段落 1–4行目 |
| peephole 結合 | 内部状態からゲートへの直接の結合。正確な時間間隔を測るタスクで性能が上がると報告 | p.19 第2段落 4–9行目 |
| 長期依存の学習 | LSTM は単純 RNN より長期依存を学習する能力が高く、紹介する応用研究の大半が LSTM を使う | p.21 第1段落 6–8行目 |
| 多層 | 記憶セルの層を複数重ねることが一般的 | p.21 第2段落 6–8行目 |

LSTM の式（忘却ゲートあり、peephole なし）：

$$
\begin{aligned}
g^{(t)} &= \phi(W^{gx}x^{(t)} + W^{gh}h^{(t-1)} + b_g)\\
i^{(t)} &= \sigma(W^{ix}x^{(t)} + W^{ih}h^{(t-1)} + b_i)\\
f^{(t)} &= \sigma(W^{fx}x^{(t)} + W^{fh}h^{(t-1)} + b_f)\\
o^{(t)} &= \sigma(W^{ox}x^{(t)} + W^{oh}h^{(t-1)} + b_o)\\
s^{(t)} &= g^{(t)} \odot i^{(t)} + s^{(t-1)} \odot f^{(t)}\\
h^{(t)} &= \phi(s^{(t)}) \odot o^{(t)}
\end{aligned}
$$

📍出典：p.20 の式（6本）、第1段落 3–10行目（h⁽ᵗ⁾ の意味、peephole を含まないこと、f⁽ᵗ⁾ = 1 で忘却ゲートなしの LSTM になること、g に tanh を使う理由）

記述から確認できる事項：誌面の s⁽ᵗ⁾ の式では入力ゲートが **i⁽ⁱ⁾** と印刷されている（PDF の画像で確認）。p.18 箇条書き「Forget gate」の同じ式では i⁽ᵗ⁾ となっているので、i⁽ᵗ⁾ の誤植と考えられる（**推測**）。上の式は i⁽ᵗ⁾ として書いた。
📍出典：p.20 の5本目の式／p.18 箇条書き「Forget gate」の式

## 9. 学習方法（論文が解説するもの）

| 項目 | 内容 | 📍出典 |
|---|---|---|
| 損失関数 | 出力 ŷ と目標 y の距離を罰する L(ŷ, y)。具体的な関数は課題による | p.8 §2.3 第2段落 4–7行目 |

## 17. 重要箇所の和訳（趣旨）

用語対応：再帰型ニューラルネットワーク（recurrent neural network, RNN）／順伝播型ネットワーク（feedforward network）／隠れ状態（hidden state）／再帰辺（recurrent edge）／時間方向の誤差逆伝播法（backpropagation through time, BPTT）／打ち切り BPTT（truncated BPTT, TBPTT）／勾配消失・勾配爆発（vanishing / exploding gradient）／長短期記憶（long short-term memory, LSTM）／記憶セル（memory cell）／内部状態（internal state）／入力ゲート・忘却ゲート・出力ゲート（input / forget / output gate）／定誤差カルーセル（constant error carousel）／双方向 RNN（bidirectional RNN, BRNN）／確率的勾配降下法（stochastic gradient descent, SGD）

**§3 冒頭（趣旨）** 📍出典：p.10 第4段落 1–11行目
【直訳（趣旨）】RNN は、隣り合う時刻をまたぐ辺を加えて時間の概念を導入した順伝播型ネットワークである。時刻 t において、再帰辺を持つノードは現在のデータ点 x⁽ᵗ⁾ と、前の状態の隠れノードの値 h⁽ᵗ⁻¹⁾ から入力を受ける。各時刻の出力 ŷ⁽ᵗ⁾ は、その時刻の隠れノードの値 h⁽ᵗ⁾ から計算される。時刻 t−1 の入力は、再帰結合を通じて時刻 t 以降の出力に影響しうる。
【意味】RNN は「今の入力」と「1つ前の隠れ状態」から新しい隠れ状態を作り、そこから出力を出す。過去の入力の影響は隠れ状態を通じて後の時刻に伝わる。

**§3.2 勾配消失・爆発（趣旨）** 📍出典：p.13 第2段落 6–15行目
【直訳（趣旨）】勾配消失・爆発の問題は、多くの時刻にわたって誤差を逆伝播するときに起こる。時刻 τ に入力を与え、時刻 t で誤差を計算する場合を考える。重みが時刻間で共有されているため、再帰辺の重みは常に同じ値である。したがって時刻 τ の入力が時刻 t の出力に与える寄与は、t − τ が大きくなるにつれて指数的に爆発するか0に近づく。
【意味】同じ重みを何度も掛け合わせることになるので、遠い過去の入力に対する勾配は極端に大きくなるか、ほぼ0になってしまう。長い時系列ほど学習が難しくなる理由。

**§3.2 TBPTT（趣旨）** 📍出典：p.14 第2段落 1–6行目
【直訳（趣旨）】打ち切り BPTT は、連続して動き続けるネットワークの勾配爆発問題に対する1つの解決策である。誤差を伝播させる時刻数の上限を定める。小さい打ち切り幅の TBPTT は勾配爆発を和らげられるが、長期依存を学習する能力を犠牲にする必要がある。
【意味】逆伝播する時刻数を制限すれば学習は安定するが、その長さより遠い過去との関係は学習できなくなる。

**§4.1 LSTM（趣旨）** 📍出典：p.17 §4.1 第1段落 1–7行目
【直訳（趣旨）】Hochreiter と Schmidhuber（1997）は、主に勾配消失問題を克服するために LSTM を導入した。このモデルは隠れ層を持つ標準的な RNN に似ているが、隠れ層の各ノードが記憶セルに置き換えられている。各記憶セルは重み1で固定された自己結合を持つノードを含み、勾配が消失も爆発もせずに多くの時刻を通過できるようにしている。
【意味】LSTM は「重み1で自分に戻る経路」を持つことで、遠い過去まで勾配を伝えられるようにした RNN。

**§6 議論（趣旨）** 📍出典：p.31 第2段落 1–3行目
【直訳（趣旨）】LSTM と BRNN は近年多くの課題で精度の記録を打ち立ててきたが、その進歩が根本的に新しいアルゴリズムではなく、新しいアーキテクチャから来ていることは注目に値する。
【意味】RNN の性能向上は、学習法そのものではなく、ネットワーク構造の工夫によってもたらされてきた。
