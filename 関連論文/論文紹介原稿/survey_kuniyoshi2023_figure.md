## 2. 画像の上半分：CBT モデルの構成図（論文の図2）

📍出典：p.4 図2 とキャプション 1–5行目

### 2.1 何の図か

**皮質–大脳基底核–視床（cortico-basal ganglia-thalamic, CBT）モデル** の構成図。脳の領域を「層・細胞種ごとの神経細胞の集団」に分け、集団どうしの結合を矢印で表している。

| 画像中の枠 | 意味 | 📍出典 |
|---|---|---|
| **Cortex S1**（左の列） | 一次体性感覚野。22 の層・細胞種の集団 | p.4 図2 キャプション 1行目 |
| **Cortex M1**（右の列） | 一次運動野。19 の層・細胞種の集団 | p.4 図2 キャプション 1行目 |
| **Basal Ganglia**（中央上） | 大脳基底核：MSN・FSI（線条体）、GPe・GPi（淡蒼球外節・内節）、STN（視床下核） | p.4 左段 第2段落 11–15行目／p.5 表1 |
| **Thalamus S1 / Thalamus M1**（中央下） | 視床。興奮性入力が優位な領域（EZ）と抑制性入力が優位な領域（IZ）に分け、それぞれ IN・TC・RE を含む | p.4 左段 第2段落 15–18行目／p.5 表1 |
| **CSN, PTN, CM/Pf**（緑の箱） | 「パロット（parrot）ニューロン」の層 | p.4 図2 キャプション 4–5行目 |

### 2.2 各集団の名前の読み方

名前は「領域_層_細胞種」の形になっている。例：

- **S1_L4_Pyr** ＝ S1 の第4層の錐体細胞（pyramidal neuron）
- **M1_L5B_PT** ＝ M1 の第5B層の錐体路ニューロン（pyramidal-tract neuron）
- **TH_M1_IZ_TC** ＝ M1 に対応する視床の IZ 領域の視床皮質ニューロン（thalamocortical neuron）

細胞種の略称（表1の脚注による）：

| 略称 | 意味 |
|---|---|
| ENGC / SBC | elongated neurogliaform cell / single bouquet cell |
| PV / SST / VIP | パルブアルブミン / ソマトスタチン / 血管作動性腸管ペプチドを発現するニューロン（抑制性の介在ニューロン） |
| Pyr | 錐体細胞 |
| CC / CS / CT / PT | 皮質–皮質 / 皮質–脊髄 / 皮質–視床 / 錐体路ニューロン |
| TC / RE | 視床皮質ニューロン / 視床網様核 |
| IN | 表1の脚注では「interpositus nucleus」と記載 |

📍出典：p.5 表1 とその脚注

注意：表1 の脚注では IN を「interpositus nucleus（中位核）」と定義しているが、視床内の細胞種としては介在ニューロン（interneuron）の略として使われることが多い（**推測**）。論文の記述どおりに説明するなら「表1では interpositus nucleus と定義されている」とするのが安全。

## 4. スライドで説明するときの要点

### 4.1 この図が示していること（論文の記述に基づく）

1. マウスの脳の複数領域（運動野・感覚野・基底核・視床・小脳）を、**細胞種ごとの LIF ニューロン集団**としてモデル化している（📍 p.4 図2、p.4 右段 第1段落 1–3行目、p.5 表1）
2. CBT モデルだけで **LIF ニューロン 176,465 個**、小脳モデルで約9万個のニューロンを使う大規模なスパイキングネットワーク（📍 p.4 右段 第1段落 2行目、p.4 右段 第3段落–p.5 左段 第1段落）
3. 1台の計算機では大きすぎるため、**富岳・GPU クラスタ・ローカル PC に分散**して同期させた（📍 p.1 Abstract 1–4行目、p.2 右段 第2段落）
4. CBT モデルの計算時間が最も長く、他の部分はその計算を待つことになる。計算ノードを1から2に増やすと約60%速くなったが、それ以上はスケーラビリティが悪化した（📍 p.9 左段 第5段落 1–7行目、第6段落、p.9 右段 第1段落 1–4行目、p.10 図7）

### 4.2 卒業研究（サロゲートモデル）との関係

- この脳モデルの各ニューロンは、**空間形状を持たない点ニューロン（LIF）** である（📍 p.4 右段 第1段落 2–3行目、M2 の LIF の式は p.3 式(1)(2)）。HH モデルや多コンパートメントモデルではない。
- 棟近先輩の卒論は、この論文を「HH モデルより膜電位応答の再現性が劣る積分発火モデルを使った大規模脳シミュレーションの例」として引用している（📍 棟近卒論 p.22 §4.5 第3段落 1–3行目、参考文献[18]）。
- つまりスライドでは、「**大規模な脳シミュレーションでは、計算の都合で単純なニューロンモデル（LIF）が使われている**」→「**詳細なモデル（HH・多コンパートメント）を軽く計算できるサロゲートがあれば、大規模シミュレーションの精度を上げられる**」という動機づけに使える（**推測**：スライドの意図の解釈）。
- ただし、Kuniyoshi らの論文自身は「計算コストのために LIF を選んだ」とは書いていない。LIF を選んだ理由は本文に記載がないので、発表では「LIF が使われている」という事実と、「その理由は計算量の削減と考えられる」という自分の解釈を分けて話すのが安全。

### 4.3 説明の例（30秒程度）

> これは Kuniyoshi らが2023年に発表した、マウスの脳と身体を同時にシミュレーションした研究の図です。上の図は大脳皮質の運動野・感覚野、大脳基底核、視床をつないだモデルで、箱の1つ1つが「ある層のある種類の細胞の集団」を表しています。このモデルだけで LIF ニューロンを約17万6千個使っています。下の図は小脳モデルで、約9万個の細胞を実際の層構造に合わせて3次元に配置しています。これだけの規模になると1台の計算機では計算できず、富岳と GPU クラスタに分散して計算しています。ここで使われているのは膜電位の閾値だけで発火を決める単純な LIF モデルで、HH モデルのようなイオンチャネルの詳細は含まれていません。
